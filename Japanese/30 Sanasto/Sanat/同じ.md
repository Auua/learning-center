## Merkitys
- **FI:** sama
- **EN:** the same
- **Ääni:** ![[anki_1560cc9cecec7399c3e80dfb53f80925.mp3]]

> [!warning] Poikkeus な-adjektiivien joukossa
> 同じ ei ota な:ta substantiivin edessä (×同じな N on virhe) — 同じ + N suoraan: 同じ意見（おなじいけん, sama mielipide）.

## Esimerkit
- 彼の日本語のレベルは私と同じ位だ。 — His Japanese level is about the same as mine.
- この文と大体同じいみの文があります。 — There is a sentence that means basically the same thing as this sentence.
- 今回のしけんは、ぜん回とほぼ同じ内ようでした。 — This exam was almost the same questions as last time.
