> [!abstract] Tilanne
> Oman ja toisen tunteen kertominen — [[Minna no Nihongo II#Luku 39]], Reference Words & Information ("気持ち Feelings"). Luvun kielioppi on syy-て-muoto: 合格して、うれしいです。 Huomaa jako: **i-adjektiivit** kuvaavat tunnetilaa, **～する-onomatopoeiat** kuvaavat tunteen fyysistä reaktiota.

## Tunneadjektiivit
| JA | FI |
|---|---|
| [[うれしい]] | iloinen, onnellinen |
| [[楽しい]]（たのしい） | mukava, hauska |
| [[寂しい]]（さびしい） | yksinäinen, ikävä |
| [[悲しい]]（かなしい） | surullinen |
| [[おもしろい]] | kiinnostava, hauska |
| [[うらやましい]] | kateellinen |
| [[恥ずかしい]]（はずかしい） | nolostunut, häpeissään |
| [[懐かしい]]（なつかしい） | kaipaava, nostalginen |

> [!warning] うれしい vs. 楽しい
> うれしい = hetkellinen ilo jostakin tapahtuneesta (sain lahjan). 楽しい = tekemisen mukavuus, joka kestää (matka oli mukava). Suomen "kiva" peittää molemmat — japanissa ne eivät vaihdu keskenään.

## Tunnereaktiot (～する)
| JA | FI |
|---|---|
| [[びっくりする]] | säikähtää, yllättyä |
| [[がっかりする]] | pettyä |
| [[うっとりする]] | haltioitua, lumoutua |
| [[いらいらする]] | ärsyyntyä, hermostua |
| [[どきどきする]] | sydän hakkaa (jännitys, pelko) |
| [[はらはらする]] | olla huolissaan, jännittää toisen puolesta |
| [[わくわくする]] | olla innoissaan |

> [!tip] どきどき vs. はらはら vs. わくわく
> どきどき = oma syke nousee. はらはら = katsot sivusta ja pelkäät toisen puolesta. わくわく = odotat innolla jotain mukavaa. Kaikki kolme ovat äänteellisiä (擬態語), ks. [[Setti — Onomatopoeettiset sanat]].
