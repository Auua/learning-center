- 私は**夕暮れ**が好きだ。部屋の窓から**暮れて**いく空を見ていると、心が安らいでくる。 → **夕暮れ**（ゆうぐれ）／**暮れて**（くれて）
- 先生の文法説明は**漠然としていて**、よく分からなかった。 → **漠然としていて**（ばくぜんとしていて）
- 日本の農業は**規模**が小さくて、一人当たりの生産性が非常に低い。これに対し、アメリカの農業は**大規模**で、機械化が進み、非常に生産性が高い。 → **規模**（きぼ）／**大規模**（だいきぼ）
- 子供の言語発達は、**概念**の形成とともに進んでいく。 → **概念**（がいねん）
- 大学生の時に経済学**概論**をとったので、経済の原理は一応分かる。 → **概論**（がいろん）
- がんの恐れがあったので精密検査をしたら、**既に**がんが進行して手遅れになっていた。 → **既に**（すでに）
- 最近は「**既製服**」とはあまり言わないで、「レディーメード」と言う。 → **既製服**（きせいふく）
- ヒトラーは**独裁者**だったが、日本にはヒトラーに当たるような人物はいなかった。 → **独裁者**（どくさいしゃ）
- ある国で外交官が罪を犯しても、その国の法律でこれを**裁く**ことはできない。 → **裁く**（さばく）
- 母は**洋裁**が得意で、小さい時私の服は全部母が作ってくれた。 → **洋裁**（ようさい）
