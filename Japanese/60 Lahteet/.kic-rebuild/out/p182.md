- 1789年のフランス**革命**より以前に、イギリスでは産業革命が起こった。産業革命は、**技術革新**、輸送方法の革新、さらには経済システムの革新をも含む、経済的な{大|だい}**変革**であった。そして、その結果、資本主義経済が成立し、イギリスは「世界の工場」の地位を{獲得|かくとく}した。 → **革命**（かくめい）／**技術革新**（ぎじゅつかくしん）／**変革**（へんかく）
- **革**のジャンパーは{格好|かっこう}よくて暖かいが、重いのが欠点だ。 → **革**（かわ）
- 人の**命**は地球より重い。 → **命**（いのち）
- **生命**の危険を感じることが何度かあったが、ジャーナリストとしての**使命**を果たすために、私は戦場深く入っていった。どんな危険が待ちかまえているか分からないが、すべての**運命**を私は受け入れようとしていた。 → **生命**（せいめい）／**使命**（しめい）／**運命**（うんめい）
- 戦国時代に日本に来たヨーロッパの{宣教師|せんきょうし}たちはキリスト教を日本に広めなければならないという非常に強い**使命**感を持っていた。 → **使命**（しめい）
- {内閣|ないかく}**総理大臣**は{衆議院|しゅうぎいん}で選出され、天皇がこれを**任命**する。総理大臣に任命されるとすぐに内閣を組織する。内閣の**大臣**や長官は総理大臣が任命する。 → **総理大臣**（そうりだいじん）／**任命**（にんめい）／**大臣**（だいじん）
- {官僚|かんりょう}の仕事をするためには、**法令**や**政令**についての幅広い知識が必要です。 → **法令**（ほうれい）／**政令**（せいれい）
- 「**領土**」は国の土地、「**{領地|りょうち}**」は封建時代の王や貴族の土地。 → **領土**（りょうど）
- 会社の経費で何か買う場合は必ず**領収書**をもらってください。 → **領収書**（りょうしゅうしょ）
- 私は仕事の**要領**が悪いので、いつも残業になってしまう。 → **要領**（ようりょう）
- 今から約400年前に{徳川家康|とくがわいえやす}が日本の国を**統一**した。とはいっても、徳川家が日本全体を**統治**するようになったわけではない。日本は約300の{藩|はん}と呼ばれる小さな国に分かれ、{藩主|はんしゅ}と呼ばれる{領主|りょうしゅ}がそれぞれの{領地|りょうち}を{治|おさ}めていたのである。 → **統一**（とういつ）／**統治**（とうち）
- 戦後、日本の経済は戦争中の**統制経済**から自由経済に{移行|いこう}したが、現在でも統制経済的な要素が強く残っている。 → **統制経済**（とうせいけいざい）
- 経営の合理化を{図|はか}るために、部や課の整理**統合**が行われた。 → **統合**（とうごう）
- この村は産業がないので、道路も橋も政府の**補助金**がなければ造ることができない。 → **補助金**（ほじょきん）
