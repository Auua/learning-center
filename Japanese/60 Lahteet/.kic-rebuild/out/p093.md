- 東京に来たばかりの▲{頃|ころ}は、人が多すぎて、道の真ん中でしばしば**立ち往生**してしまった。 → **立ち往生**（たちおうじょう）
- 人は**往々にして**、他の人も自分と同じように感じていると考えてしまう。 → **往々にして**（おうおうにして）
- 家から会社まで、1時間半。**往復**で、3時間。1日約3時間は電車の中というわけです。 → **往復**（おうふく）
- 年をとって病気になると、**回復**が遅い。 → **回復**（かいふく）
- 毎日の予習、**復習**をきちんとすれば、テストの前にそれほど勉強しなくても{大丈夫|だいじょうぶ}です。 → **復習**（ふくしゅう）
- {初級|しょきゅう}の日本語クラスでは先生のモデルに{従|したが}って何回も**反復**練習をしました。 → **反復**（はんぷく）
- チームで仕事をしていると、連絡をよくしておかないと、仕事が**重複**してしまう。 → **重複**（ちょうふく）
- **雑誌**には{週刊誌|しゅうかんし}もあるし{月刊誌|げっかんし}もある。最近は週刊誌が{非常|ひじょう}に多くなりました。 → **雑誌**（ざっし）
- 「{日記|にっき}」と「**日誌**」は違います。「日記」というのは個人が自分のためにつけるもので、「日誌」というのは会社や学校などでみんなのためにつけるものです。 → **日誌**（にっし）
