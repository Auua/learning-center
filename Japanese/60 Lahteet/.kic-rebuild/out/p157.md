- 日本では、**石炭**は以前は{貴重|きちょう}な燃料だったが、現在はほとんど使われなくなった。 → **石炭**（せきたん）
- 私は小学校の{頃|ころ}**体育**が{嫌|きら}いで、体育の時間になると、いつも＊お{腹|なか}が痛いとうそを言って、授業を見学していた。（＊「おなか」は常用漢字外の読み方。） → **体育**（たいいく）
- 近所の同じくらいの子供と比べると、うちの子供は**発育**が遅いようだ。 → **発育**（はついく）
- うちでは庭でトマトやキュウリを**育てて**います。 → **育てて**（そだてて）
- {肥料|ひりょう}をやると**生育**が速くなるが、たくさんやればいいというものではない。 → **生育**（せいいく）
- 私は東京で生まれて、東京で**育ち**ました。 → **育ち**（そだち）
- 昔は**絹**の{着物|きもの}と**木綿**の着物があったが、今は着物と言えばたいてい絹だ。 → **絹**（きぬ）／**木綿**（もめん）
- **綿**から{綿糸|めんし}を作り、綿糸で**木綿**を作る。 → **綿**（わた）／**木綿**（もめん）
- **組織**が大きくなると、どうしても社内のコミュニケーションが悪くなる。 → **組織**（そしき）
- 私は今雑誌の**編集**の仕事をしています。編集の仕事は初めてですが、**編集長**がとても親切な人で、いろいろと教えてくれます。 → **編集**（へんしゅう）／**編集長**（へんしゅうちょう）
