**III.　＿＿＿の言葉の読み方を書きなさい。**

- 自分の{将来|しょうらい}は**真剣に**考えなければならないが、{深刻|しんこく}になる必要はない。 → **真剣に**（しんけんに）
- 経験のある{教師|きょうし}はいろんな場面を**経験**しているので、学生の心の動きがよく分かる。 → **経験**（けいけん）
- スキューバダイビングの素晴らしさは実際に**体験**した人でないと分からない。 → **体験**（たいけん）
- 電車の中で子供が**騒いで**いるのに、全然{叱|しか}らない親がいる。周りの{迷惑|めいわく}も考えてほしい。 → **騒いで**（さわいで）
- 外が**騒がしい**ので窓を開けて見てみると、映画のロケをしていた。 → **騒がしい**（さわがしい）
- {久|ひさ}しぶりに高校時代の友達に会って、近所の飲み屋で**大騒ぎ**した。 → **大騒ぎ**（おおさわぎ）
- 雨のために**試合**が延期になった。 → **試合**（しあい）
- 地下の食料品売り場でいろんな食べ物を**試食**しているとそれだけで＊お{腹|なか}がいっぱいになった。（＊「おなか」は常用漢字外の読み方。） → **試食**（ししょく）
- 自分の日本語能力を**試す**ために日本語能力**検定試験**を受けてみた。 → **試す**（ためす）／**検定**（けんてい）／**試験**（しけん）
- 先月{彼女|かのじょ}の両親に会って**正式**に結婚を{申|もう}し込んだ。 → **正式に**（せいしきに）
- 役人は**形式**ばかり気にして、実質をあまり考えない{傾向|けいこう}がある。 → **形式**（けいしき）
- 1970年に{大阪|おおさか}でアジアで初めての**万博**が開かれた。 → **万博**（ばんぱく）
- うちの店は**薄利多売**なので、たくさんお客さんに来てもらわないと商売にならない。 → **薄利多売**（はくりたばい）
- {彼|かれ}は今新しいガールフレンドに**夢中になって**いて、勉強のことはすっかり忘れている。 → **夢中になって**（むちゅうになって）
