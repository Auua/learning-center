> [!question] Milloin kumpi?
> Kysy: **havaitsenko teon (näen, kuulen, tunnen sen), vai puhunko siitä käsitteenä?** Havainto → の. Käsite, sääntö, unelma tai lauseen loppu ennen です → こと.

## Vertailutaulukko
| Tilanne | の | こと | Esimerkki |
|---|---|---|---|
| Aistiverbit (見る, 聞く, 聞こえる, 感じる) | ✓ | ✗ | 子どもが泳ぐ**の**を見た。 |
| Odottaa, auttaa, pysäyttää (待つ, 手伝う, 止める) | ✓ | ✗ | バスが来る**の**を待つ。 |
| Predikaattina ennen です | ✗ | ✓ | 夢は日本語を話す**こと**です。 |
| Viestintä (話す, 伝える, 約束する) | ✗ | ✓ | 来る**こと**を伝えた。 |
| Kiinteät: ことができる, ことがある, ことにする | ✗ | ✓ | 泳ぐ**こと**ができる。 |
| 好き, 上手, 嫌い, 楽しい, 難しい | ✓ (luontevin) | ✓ (yleistävä) | 走る**の**が好き ／ 走る**こと**が好き |

## Muistisääntö
**の = osoitan sormella** tapahtumaa, joka tapahtuu tässä ja nyt.
**こと = kirjoitan sanakirjaan** määritelmän asiasta.
Kolmas tapa, [[ます-vartalo substantiivina (連用形名詞)]] (始まり, 話し合い), ei ole valinta näiden välillä: se tuottaa vakiintuneen sanan eikä toimi vapaasti kaikilla verbeillä.

## Minimiparit
| A | B | Ero |
|---|---|---|
| 鳥が鳴く**の**が聞こえる | ×鳥が鳴く**こと**が聞こえる | Kuuleminen on aistihavainto, vain の |
| 趣味は本を読む**こと**です | ×趣味は本を読む**の**です | Ennen です vain こと |
| 走る**の**は楽しい | 走る**こと**は楽しい | Oma kokemus vs. yleinen toteamus |
| 話の始まり | 話が始まること | Substantiivi "alku" vs. "se, että tarina alkaa" |
