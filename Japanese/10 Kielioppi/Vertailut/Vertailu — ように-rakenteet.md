> [!question] Milloin mikäkin?
> Katso ensin, **mitä ように:n jälkeen tulee** (なる, する, 言う, lause vai ei mitään). Katso sitten **verbin muoto** (perusmuoto, potentiaali vai ない形). Jälkimmäinen kertoo, onko kyse kyvystä, tavasta vai tilasta.

## Päätöspuu
1. ように + **なる** → muutos tapahtui → [[Vようになります (kyvyn tai tilan muutos)]]
   - potentiaali (泳げる) → **kyky** syntyi: opin uimaan
   - perusmuoto (泳ぐ) → **tapa/käytös** muuttui: aloin uida
   - ei-tahdonalainen perusmuoto (見える, わかる) → **tila/kyky** muuttui: aloin nähdä
2. ように + **する / している** → oma pyrkimys tai järjestely
   - perusmuoto tai ない形 → **pyrin tekemään / välttämään** → [[Vようにする・ようにしてください (huolehtia etta)]] (kerran), [[Vようにしています (tavakseen pyrkiminen)]] (tapa)
   - potentiaali (使える, 読める) → **järjestän niin, että voi** → [[Vようにする・ようにしてください (huolehtia etta)]]
3. ように + **言う / 頼む / 注意する** → epäsuora käsky → [[Vようにいう・注意する・伝える・頼む (epasuora kehotus)]]
4. ように + **muu lause** → tarkoitus "jotta" → [[Vように (jotta, niin etta)]]
   - verbin pitää olla ei-tahdonalainen: potentiaali (話せる), valmiiksi ei-tahdonalainen perusmuoto (聞こえる) tai ない形 (忘れない)
   - tahdonalainen perusmuoto (話す, 行く) → käytä ために
5. Vます + ように. (lause loppuu) → toive/rukous → [[Vますように (toive, kunpa)]]
6. Lauseen alussa Vた/ご存じの + ように、 → "kuten" → [[普通形ように (kuten, niin kuin)]]
7. N + のように → "kuin, -n tavoin" → [[～のようだ・～のような・～のように (vertailu, esimerkki)]]

## Vertailutaulukko
| Rakenne | Perusmuoto (辞書形) | Potentiaali (可能形) | ない形 |
|---|---|---|---|
| 〜ように、(lause) — jotta | vain ei-tahdonalaiset: 聞こえるように | tavallisin: 話せるように | kaikki verbit: 忘れないように |
| 〜ようになる — muutos | tapa muuttui: 泳ぐようになった | kyky syntyi: 泳げるようになった | yleensä 〜なくなる: 泳がなくなった |
| 〜ようにする — pyrkimys | yritän: 早く起きるようにする | järjestän: 使えるようにする | vältän: 遅れないようにする |
| 〜ようにしている — tapa | pyrin aina: 野菜を食べるようにしている | (harvinainen) | pyrin välttämään: 食べないようにしている |
| 〜ように言う — käsky | 来るように言われた | — | 遅れないように言われた |
| 〜ますように — toive | 晴れますように | 合格できますように | 降りませんように |

## Muistisääntö
**Potentiaali = kyky.** 〜ようになる + potentiaali on uusi kyky, 〜ようにする + potentiaali tekee jostain mahdollista. **Perusmuoto = teko tai tapa.** 〜ようになる + perusmuoto on uusi tapa, 〜ようにする + perusmuoto on oma yritys. Tarkoitus-ように hylkää tahdonalaisen perusmuodon, koska tavoitteen täytyy olla tila eikä teko.

## Minimiparit
| A | B | Ero |
|---|---|---|
| 泳げるようになった | 泳ぐようになった | A: opin uimaan (kyky). B: aloin uida säännöllisesti (tapa) |
| 早く起きるようにする | 早く起きられるようにする | A: yritän herätä aikaisin. B: järjestän niin, että pystyn heräämään (esim. menen ajoissa nukkumaan) |
| 泳ぐようになった | 泳ぐようにしている | A: muutos on tapahtunut. B: pyrin tietoisesti uimaan |
| 泳ぐようにする | 泳ぐようにしている | A: kertaluonteinen päätös ("yritän uida"). B: jatkuva tapa ("pyrin aina uimaan") |
| 日本語が話せるように勉強する | 日本で働くために勉強する | A: tavoite on tila/kyky (potentiaali → ように). B: tavoite on tahdonalainen teko (→ ために) |
| ×わかれるように | わかるように | わかる on valmiiksi ei-tahdonalainen, joten se ei saa potentiaalia |
| 合格したい | 合格できますように | A: oma halu. B: rukous lopputuloksen puolesta |
| 言ったように | 子どものように | A: kuten sanoin (viittaus). B: kuin lapsi (vertaus) |

## Testilauseet itselle

2. 最近、朝ご飯をちゃんと食べる＿＿＿＿＿＿＿。(tavaksi, muutos) → ようになった
3. 健康のために、毎日歩く＿＿＿＿＿＿。(pyrin aina) → ようにしている
4. お年寄りでも使える＿＿＿＿＿＿。(järjestimme) → ようにした
5. 後ろの人にも聞こえる＿＿＿、大きな声で話す。 → ように (jotta)

7. 明日は雨が降りません＿＿＿＿。 → ように (toive)
8. 先生に、もっと勉強する＿＿＿言われた。 → ように (epäsuora käsky)

#flashcards/compare/n4/saanto

ように-rakenteet: mitkä kaksi asiaa ratkaisevat merkityksen?
?
1) Mitä ように:n jälkeen tulee (なる / する / 言う / lause / ei mitään). 2) Verbin muoto: potentiaali = kyky, perusmuoto = teko/tapa, ない形 = vältettävä asia.

Muistisääntö: potentiaali vs. perusmuoto ように-rakenteissa?
?
Potentiaali = kyky (ようになる: uusi kyky; ようにする: tehdä mahdolliseksi). Perusmuoto = teko tai tapa (ようになる: uusi tapa; ようにする: oma yritys).

#flashcards/compare/n4/minimipari

泳げるようになった vs. 泳ぐようになった: mikä ero?
?
泳げる = opin uimaan (kyky); 泳ぐ = aloin uida säännöllisesti (tapa).

早く起きるようにする vs. 早く起きられるようにする: mikä ero?
?
起きる = yritän herätä aikaisin; 起きられる = järjestän olosuhteet niin, että pystyn heräämään.

泳ぐようになった vs. 泳ぐようにしている: mikä ero?
?
ようになった = muutos on tapahtunut; ようにしている = pyrin tietoisesti uimaan.

日本語が話せるように勉強する vs. 日本で働くために勉強する: miksi eri rakenne?
?
話せる (potentiaali) on tila → ように; 働く on tahdonalainen teko → ために.

合格したい vs. 合格できますように: mikä ero?
?
たい = oma halu; ますように = rukous lopputuloksen puolesta.
