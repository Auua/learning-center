> [!abstract] Ydin
> [[Tahtomuoto よう]] + とする kuvaa hetkeä jolloin joku **on juuri yrittämässä/tekemäisillään** jotain — usein toinen tapahtuma keskeyttää sen. Kielteinen としない kuvaa jatkuvaa haluttomuutta/kieltäytymistä yrittää.

## Merkitys
- **ようとする (FI):** yrittää tehdä, olla tekemäisillään
- **ようとしない (FI):** ei edes yritä, kieltäytyy yrittämästä
- **EN:** to be about to try to do / to refuse to (even try to)

## Muodostus
| Kaava | Merkitys | Esimerkki |
|---|---|---|
| [[Tahtomuoto よう]] + とした + とき/ら | keskeytetty yritys | 今朝**出かけようとしたとき**、電話がかかってきた。 |
| | | 電話に**出ようとしたら**、切れてしまった。 |
| [[Tahtomuoto よう]] + としたが、〜られない | yritys epäonnistuu | 彼女のことを**忘れようとしたが**、忘れられない。 |
| [[Tahtomuoto よう]] + としない | jatkuva kieltäytyminen yrittää | 彼はほかの人の意見を**聞こうとしない**。 |
| | | いくら勉強しろと言っても、彼は**勉強しようとしない**んです。 |

## Nyanssi ja rajoitukset
- ようとしたとき/たら korostaa **ajallista keskeytystä**: yritys oli juuri alkamassa kun jotain muuta tapahtui.
- ようとしない (kielteinen, jatkuva) kuvaa asennetta/luonnetta — henkilö ei ole edes halukas yrittämään, ei vain epäonnistunut kerran.
- Ero たい:hin: たい on suora halu; ようとする korostaa itse **yrittämisen tekoa/hetkeä**, usein juuri ennen mahdollista epäonnistumista tai keskeytystä.

## Sekaannusvaara
- たばこはやめましたか。……いいえ。やめようとしたんですが、やめられなかったんです。 — ようとする (yritti) + られない (potentiaalin kielto, ei onnistunut) esiintyvät usein yhdessä kuvaamaan epäonnistunutta yritystä.

## Kortit
#flashcards/grammar/n3

今朝＿＿＿＿＿＿＿とき、電話がかかってきた。(出かける, keskeytetty yritys)
?
出かけようとした — Tahtomuoto + とした + とき, yritys keskeytyi juuri alkaessaan.

Mitä eroa on ようとしない:llä ja 〜ない:llä (esim. 聞こうとしない vs. 聞かない)?
?
聞こうとしない korostaa aktiivista haluttomuutta edes yrittää; 聞かない on neutraalimpi toteamus siitä ettei kuuntele.
