> [!abstract] Ydin
> の yhdistää kaksi substantiivia niin, että N1 määrittää N2:ta: "N1:n N2". Luvussa 1 N1 on organisaatio/ryhmä johon N2 kuuluu (kuuluvuus); luvussa 2 の laajenee kattamaan myös suoran omistuksen ("minun"); luvussa 3 の kertoo valmistajan/alkuperän ("missä/kenen tekemä").

## Merkitys
- **FI:** N1:n N2 (kuuluvuus/omistus)
- **EN:** N2 of N1 / N1's N2

## Muodostus
| Mihin liittyy | Kaava | Esimerkki |
|---|---|---|
| Kuuluvuus (Luku 1) | N1 (ryhmä) + の + N2 (jäsen) | IMC**の**社員 = IMC:n työntekijä |
| Aihe (Luku 2) | N1 (aihe) + の + N2 (esine) | コンピューター**の**本 = tietokoneita käsittelevä kirja |
| Omistus (Luku 2) | わたし + の (+ N2 tai yksin) | わたし**の**（本） = minun (kirjani) |
| の yksinään korvaamassa N2:ta | N1のN2 → N1の (kun N2 on jo selvä kontekstista, EI koskaan jos N2 on henkilö) | この傘はわたしのです。 = Tämä sateenvarjo on minun. |
| Alkuperä/valmistaja (Luku 3) | maa/yritys + の + tuote | 日本**の**コンピューター = Japanissa valmistettu tietokone |

## Nyanssi ja rajoitukset
- の voi seistä yksin lauseen lopussa (N2 jätetään pois), kun toistaminen olisi tarpeetonta — hyvin yleistä luvussa 2.
- **Poikkeus:** jos N2 on henkilö, の-lyhennettä ei voi käyttää — あれはだれのかばんですか。→ 佐藤さんの**かばん**です (ei ×佐藤さんのです tässä merkityksessä, koska se tarkoittaisi "Satoin omaa" jotain muuta).
- Ei käy kun: N1 ja N2 eivät ole substantiiveja — adjektiivien yhdistämiseen käytetään muita rakenteita ([[Minna no Nihongo I#Luku 16]]).

## Sekaannusvaara
の on aina "kiinteä" järjestys N1**の**N2 — järjestystä ei voi kääntää kuten suomessa genetiivi joskus voi ("kirjan kansi" vs "kannen kirja" eivät toimi samoin japanissa: 本の表紙 on aina tässä järjestyksessä).

## Kortit
#flashcards/grammar/n5

IMCの社員 — mikä on N1 ja mikä N2?
?
N1 = IMC (johon kuulutaan), N2 = 社員 (työntekijä). Suomeksi "IMC:n työntekijä".

Miksi の voi joskus seistä yksin lauseen lopussa?
?
Se korvaa koko N1のN2-rakenteen jälkiosan (N2), kun asia on jo selvä keskustelusta: このかばんはわたしの(かばん)です。
