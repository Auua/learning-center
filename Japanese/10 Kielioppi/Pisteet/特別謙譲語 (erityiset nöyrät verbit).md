> [!abstract] Ydin
> Oman (tai oman ryhmän) teon **nöyrät erityisverbit**: 行く/来る → 参る, いる → おる, 言う → 申す, する → いたす, 食べる/飲む/もらう → いただく, 見る → 拝見する, 聞く/訪ねる → 伺う, 知る → 存じる.

## Merkitys
- **FI:** (minä) menen / olen / sanon / teen / syön / katson — nöyrästi
- **EN:** special humble verbs

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 行く・来る → 参る | 日本から**参りました**。 |
| いる → おる | 研究室に**おります**。 |
| 言う → 申す | ミラーと**申します**。 |
| する → いたす／食べる・もらう → いただく | わたしが**いたします**。お菓子を**いただきます**。 |
| 見る → 拝見する／聞く・訪ねる → 伺う | お手紙を**拝見しました**。あした**伺います**。 |

## Nyanssi ja rajoitukset
- Subjekti on puhuja tai puhujan ryhmä (oma yritys, oma perhe) — ei koskaan kuulija.
- 参る, 申す, いたす, おる ovat myös "kohteliaisuuden" (丁重語) verbejä: ne kunnioittavat kuulijaa, vaikka teko ei kohdistuisi kehenkään (電車が参ります).
- 申す esittäytymisessä: ～と申します = nimeni on…

## Sekaannusvaara
- 参る (minä menen, nöyrä) vs. いらっしゃる (toinen menee, kunnioittava) — ×先生が参ります.
- いただく (minä saan/syön) vs. くださる (toinen antaa minulle).
