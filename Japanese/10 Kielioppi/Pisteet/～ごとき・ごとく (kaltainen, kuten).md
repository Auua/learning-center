> [!abstract] Ydin
> ごとく／ごとき = **kirjallinen ように／ような**: "kuten, kaltainen"; ごとき + N (vähättelevä) = "kaltaiseni".

## Merkitys
- **FI:** kuten, kaltainen (kirjallinen)
- **EN:** like, as (classical)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N の + ごとく | 光陰矢**のごとし**。 |
| V + がごとく | 彼は何も知らないかの**ごとく**振る舞った。 |
| N + ごとき + N（vähättely） | 私**ごとき**に、そんな大役は無理です。 |

## Nyanssi ja rajoitukset
- ごとく (adverbi) = ように; ごとき (määre) = ような; ごとし (predikaatti) = ようだ.
- N + ごとき = vähättelevä: 私ごとき (kaltaiseni vähäpätöinen).
- Sananlaskuissa: 光陰矢のごとし (aika rientää kuin nuoli).
