> [!abstract] Ydin
> と同時に ilmaisee, että kaksi ominaisuutta/tapahtumaa pätee **täsmälleen samaan aikaan** — joko kaksi rinnakkaista ominaisuutta (on sekä X että Y) tai kaksi tunnetta/tapahtumaa jotka syntyvät yhtä aikaa.

## Merkitys
- **FI:** samaan aikaan kuin, sekä...että... yhtäaikaisesti
- **EN:** at the same time as, both X and Y simultaneously

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + であると同時に + N2（でもある） | 邦楽は日本の民族音楽**であると同時に**人類全体の財産である。 |
| | 彼は作曲家**であると同時に**演奏家でもある。 |
| 普通形 + と同時に | 酒は薬になる**と同時に**毒にもなる。 |
| | 遅く帰ってきた娘の顔を見て、ホッとする**と同時に**腹が立った。 |

## Nyanssi ja rajoitukset
- Kaksi rinnakkaista ominaisuutta/tunnetta esitetään **yhtä totena samanaikaisesti**, ei peräkkäisyytenä.
- Yleinen kaava kaksoisominaisuuksien kuvaamiseen: NはAであると同時にBでもある.

## Sekaannusvaara
- [[～とともに (yhdessa, samalla)]]: とともに korostaa kahden **toiminnan** rinnakkaisuutta (usein molemmat aktiivisia tekoja); と同時に sopii paremmin kahden **ominaisuuden/tunteen/tilan** samanaikaisuuteen, mukaan lukien näennäisesti ristiriitaiset parit (薬になると同時に毒にもなる).
