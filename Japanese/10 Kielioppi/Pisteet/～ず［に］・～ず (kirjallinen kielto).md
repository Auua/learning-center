> [!abstract] Ydin
> ず［に］ on [[Vて・Vないで (tapa, keino)]]:n ないで:n muodollinen, kirjallinen vastine — "tekemättä jotakin". ず (ilman に:tä) toimii myös lauseita yhdistävänä syy/rinnastuskonjunktiona.

## Merkitys
- **FI:** tekemättä, ilman että (muodollinen)
- **EN:** without doing (formal register)

## Muodostus
| Kaava | Käyttö | Esimerkki |
|---|---|---|
| V(ない-vartalo) + ずに + V2 | tapa/keino (muodollinen ないで) | 会社へ**行かずに**パソコンを使って自宅で仕事をする人が増えている。 |
| | | 地震のときは、**あわてずに**落ち着いて行動してください。 |
| | | 休みの日は何も**せず**、うちでのんびりしていた。 |
| V(ない-vartalo) + ず、+ V2 | syy/rinnastus (kirjallinen) | 子どもの熱が一日中**下がらず**、心配しました。 |
| | | 山田さんは6年間、一度も**遅刻せず**、一日も休まなかった。 |

## Nyanssi ja rajoitukset
- ⚠ する:n ない-vartalo ず-muodossa on epäsäännöllinen: せず (ei ×しず) — muista tämä poikkeus erikseen.
- に voidaan jättää pois erityisesti kirjallisessa tekstissä tai kun ず päättää lausekkeen ennen pilkkua (ず,).
- Ilman に:tä (pelkkä ず + pilkku) rakenne toimii samaan tapaan kuin なくて — ilmaisee syyn tai rinnastaa kaksi tilaa (硬すぎず、軟らかすぎず、"ei liian kova eikä liian pehmeä").

## Laajennus: もせずに
も lisättynä ずに-rakenteeseen korostaa ettei edes itsestään selvää tekoa tehty (医者に行きもせずに) — ks. [[～もせずに (ei edes tehnyt)]] (Chuukyuu II Luku 21).

## Sekaannusvaara
- [[Vて・Vないで (tapa, keino)]] on tämän puhekielinen/neutraali vastine: 火を使わないで料理をしています ↔ 火を使わずに料理をしています (sama merkitys, ず on kirjallisempi/muodollisempi).
- Muista epäsäännöllinen する→せず (ei しず) — yleisin virhe tässä rakenteessa.

## Kortit
#flashcards/grammar/n3

地震のときは、＿＿＿＿＿＿落ち着いて行動してください。(あわてる, muodollinen kielto)
?
あわてずに — ない-vartalo + ずに, muodollinen ないで:n vastine.

Miksi する:n ず-muoto on せず eikä しず?
?
する on epäsäännöllinen verbi jonka ない-vartalo on せ (しない ei せない), joten ず-muoto on せず.
