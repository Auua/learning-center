> [!abstract] Ydin
> あんまり (とても/あまりに:n puhekielinen muoto) vahvistaa から-syylauseen — "koska oli aivan liikaa X, niin Y" — usein reaktiona johonkin äärimmäiseen tilanteeseen.

## Merkitys
- **FI:** koska oli aivan liikaa/liian, koska niin kovasti
- **EN:** because it was just too much (colloquial intensifier + reason)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| あんまり + 普通形 + から | あんまり落ち込んでいる**から**、人身事故でも起こしたのかと思った。 |
| | 電気料金があんまり高いもんだ**から**、調べてもらったら、やっぱり電力会社の間違いだった。 |
| | 電話をかけてきた相手の言葉使いがあんまり失礼だった**から**、思わず切ってしまった。 |
| | どうしてこんなに遅れたの? あんまり遅い**から**、心配したよ。 |

## Nyanssi ja rajoitukset
- あんまり on puhekielinen muoto sanoista あまりに/とても — käytetään tässä syylauseen alussa korostamaan **äärimmäisyyttä**, joka johti jälkimmäiseen reaktioon/johtopäätökseen.
- Yhdistyy usein もんだから:n kanssa (ks. [[もの・もんだから (perusteleva syy)]]) tehostamaan puhekielistä selittelevää sävyä.
- Selvästi puhekielinen — ei sovi kirjoitettuun tekstiin.
