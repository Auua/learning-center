> [!abstract] Ydin
> に応じて ilmaisee, että jälkimmäinen toiminta **mukautuu/vastaa** edellä mainittuun tekijään — usein aktiivinen sopeutuminen pyyntöön, tarpeeseen tai tilanteeseen.

## Merkitys
- **FI:** sen mukaan kuin, vastauksena, mukautuen
- **EN:** in response to, according to (with active adaptation)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + に応じて | 会員のうち3人は既に請求**に応じて**支払いを済ませている。 |
| | 市は市民の要望**に応じて**、図書館を夜9時まで開くことにした。 |
| | その企業は取引先の注文**に応じて**、製品の開発を進めてきた。 |
| | 大学は学生の要求**に応じて**大学の試験制度を改めることを約束した。 |

## Nyanssi ja rajoitukset
- Korostaa **aktiivista mukautumista/vastaamista** johonkin pyyntöön, tarpeeseen tai muutokseen — ei pelkkää riippuvuussuhdetta.
- Yleinen virallisissa/liike-elämän konteksteissa (yritys, laitos, hallinto vastaa asiakkaan/kansalaisen tarpeeseen).

## Sekaannusvaara
- [[～によって (riippuen, vaihtelu)]]: kuvaa passiivista vaihtelua/riippuvuutta (文化は国によって違う — "vaihtelee maan mukaan"); に応じて kuvaa **aktiivista mukautumista** johonkin pyyntöön tai tarpeeseen, usein subjektin tietoisena toimintana.
