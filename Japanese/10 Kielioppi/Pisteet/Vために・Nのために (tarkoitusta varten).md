> [!abstract] Ydin
> ために ilmaisee tavoitteen **tahdonalaiselle** verbille (vrt. [[Vように (jotta, niin etta)]], joka vaatii ei-tahdonalaisen) — tai substantiivin kanssa se nimeää hyödynsaajan/päämäärän jolle jotain tehdään.

## Merkitys
- **FI:** jotta, jonkin/jonkun vuoksi/hyväksi
- **EN:** in order to, for the sake of

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(辞書形, tahdonalainen) + ために | 将来自分の**店を持つために**、貯金しています。 |
| | 盆踊りに**参加するために**、毎日練習しています。 |
| N + の + ために | **健康のために**、何かしていますか。 |
| | **結婚のために**、貯金するんですか。 |
| Henkilö + の + ために | ベートーベンがある**女の人のために**、作った曲です。 |

## Nyanssi ja rajoitukset
- Verbi ために:n edellä on aina **tahdonalainen** (辞書形) — ei potentiaali, ei kielto, ei tilaverbi (niissä käytetään [[Vように (jotta, niin etta)]]).
- N + のために on kaksijakoinen: (1) tavoite/päämäärä ("terveyden vuoksi") tai (2) hyödynsaaja, jolle jotain tehdään ("erään naisen vuoksi/hyväksi tehty kappale").

## Sekaannusvaara
- [[Vように (jotta, niin etta)]] vaatii ei-tahdonalaisen verbin (potentiaali, kielto): 泳げるように練習する (jotta voisin uida) vs. 泳ぐために練習する (uidakseni, molemmat toimivat mutta eri painotuksella) — MNN opettaa systemaattisen jaon: tahdonalainen → ために, ei-tahdonalainen → ように.
- ⚠ [[～ため［に］・ためだ (syy, ei tarkoitus)]] (Chuukyuu I Luku 9) käyttää samaa kirjoitusasua ために mutta täysin eri merkityksessä: objektiivinen, jo tapahtunut **syy** (ビザを取らなかったために、入国できなかった), ei tuleva tahdonalainen tavoite. Erota kontekstista: tuleva tavoite (tämä muistiinpano) vs. jo tapahtunut syy (Luku 9).

## Kortit
#flashcards/grammar/n4

将来自分の店を＿＿＿＿＿＿、貯金しています。(持つ, tahdonalainen tavoite)
?
持つために — tahdonalainen verbi (辞書形) + ために.

Miksi 泳げるように eikä 泳げるために?
?
Potentiaalimuoto (泳げる) on ei-tahdonalainen — sille käytetään aina ように, ei ために.

#flashcards/grammar/n4/muodostus

V(辞書形)ために + tahdonalainen verbi :: V(辞書形, tahdonalainen) + ために. Esim. 将来自分の店を持つために、貯金しています。
Nのために + substantiivi :: N + の + ために. Esim. 健康のために、何かしていますか。
Nのために + henkilö (hyödynsaaja) :: Henkilö + の + ために. Esim. ある女の人のために、作った曲です。

#flashcards/grammar/n4/nyanssi

Millainen verbin täytyy olla ennen ために (V(辞書形)ために)?
?
Tahdonalainen 辞書形; ei potentiaali, ei kielto, ei tilaverbi (niissä käytetään ように).

Mitä kahta merkitystä N+のために voi ilmaista?
?
(1) tavoite tai päämäärä (健康のために, terveyden vuoksi) tai (2) hyödynsaaja, jolle jotain tehdään (女の人のために).

#flashcards/grammar/n4/sekaannus

Kumpi: ために vai ように, kun verbi on tahdonalainen vai ei-tahdonalainen?
?
Tahdonalainen verbi → ために; ei-tahdonalainen (potentiaali, kielto) → ように.

Miten tarkoitus-ために eroaa syy-ために:sta (ため［に］・ためだ)?
?
Tarkoitus-ために ilmaisee tulevaa tahdonalaista tavoitetta; syy-ために ilmaisee objektiivisen, jo tapahtuneen syyn (ビザを取らなかったために、入国できなかった).
