> [!abstract] Ydin
> N 抜きで = **"ilman N:ää, jättäen N pois"**; N を抜きにしては〜ない = **"ilman N:ää ei voi"**.

## Merkitys
- **FI:** ilman, jättäen pois
- **EN:** without, leaving out

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + 抜きで | 朝ご飯**抜きで**会社に行った。 |
| N + 抜きの + N | わさび**抜きの**すし |
| N を抜きにしては + kielto | 彼の協力**を抜きにしては**、成功しなかった。 |
| 冗談は抜きにして（vakavasti） | **冗談は抜きにして**、本当の話をしよう。 |

## Nyanssi ja rajoitukset
- Arkinen: 〜抜き = ilman (ruokatilaukset: わさび抜き).
- を抜きにしては〜ない = N on välttämätön.
- 冗談は抜きにして = vitsit sikseen.
