> [!abstract] Ydin
> っぱなし kuvaa tilaa joka on jätetty **huolimattomasti/tarkoituksella hoitamatta** — asia jäi kesken, päälle, auki tms. eikä kukaan tehnyt sille mitään. Usein moittiva tai valittava sävy.

## Merkitys
- **FI:** jätetty (huolimattomasti) siihen tilaan, koko ajan päällä/auki ilman huolenpitoa
- **EN:** left in a state (negligently), keeps -ing without stopping to fix it

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(ます-vartalo) + っぱなし | 洗濯物が4、5日前から干し**っぱなし**だ。 |
| | 1週間前から階段の前にバイクが置き**っぱなし**にしてある。 |
| | 今朝から立ち**っぱなし**だから、ちょっと休もう。 |
| | 目覚まし時計が鳴り**っぱなし**だったよ。 |
| | 階段の蛍光灯がつき**っぱなし**にしています。 |

## Nyanssi ja rajoitukset
- Sisältää usein **moittivan/valittavan sävyn**: asia jätettiin hoitamatta vaikka olisi pitänyt tehdä jotain (窓を開けっぱなし = ikkuna jäi auki huolimattomasti).
- Poikkeuksena 立ちっぱなし, 座りっぱなし: näissä ei ole moitetta, vaan kuvataan fyysistä rasitusta pitkästä samassa asennossa olosta.
- Eroaa [[～ている (parhaillaan, tilan tulos)]]:sta: ている kuvaa neutraalisti jatkuvaa tilaa (電気がついている = valo on päällä), kun taas っぱなし korostaa että tila on jäänyt **tahattomasti/huolimattomasti** eikä kukaan ole puuttunut siihen.

## Sekaannusvaara
- 電気がついている（neutraali: valo on päällä） vs 電気がつけっぱなしだ（moittiva: valo on jätetty päälle huolimattomasti, olisi pitänyt sammuttaa）.
