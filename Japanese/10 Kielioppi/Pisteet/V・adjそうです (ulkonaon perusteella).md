> [!abstract] Ydin
> Verbin/adjektiivin vartaloon liitetty そうです ilmaisee ulkonäön/tunnun perusteella tehdyn päätelmän — "näyttää siltä että" tai "on juuri tapahtumaisillaan". Eri kielioppi kuin [[そうです (niin on)]] (substantiivilauseen vahvistus).

## Merkitys
- **FI:** näyttää siltä että, vaikuttaa (ulkonäön perusteella), on juuri tapahtumaisillaan
- **EN:** looks like, seems, is about to (based on appearance)

## Muodostus
| Kaava | Merkitys | Esimerkki |
|---|---|---|
| V(ます-vartalo) + そうです | tapahtuma on juuri alkamaisillaan | 今にも雨が**降りそうです**。 |
| | | 上着のボタンが**とれそうです**よ。 |
| い-adj(〜い pois) + そうです | näyttää siltä (ulkonäkö) | おいし**そう**ですね。 |
| な-adj + そうです | näyttää siltä (ulkonäkö) | まじめ**そう**ですね。 |
| そう + な + N（Chuukyuu I L3） | määrittää seuraavaa substantiivia | 雨が降り**そうな**日は、洗濯をしません。／怖**そうな**犬ですね。 |
| そう + に + V/adj（Chuukyuu I L3） | määrittää verbiä/adjektiivia | みんな楽し**そうに**歌ったり、踊ったりしています。 |
| ない → なさそう（Chuukyuu I L3） | kielteinen ulkonäkö | 楽しく**なさそう**だね。／あまり丈夫じゃ**なさそう**だね。 |
| V(ます-vartalo) + そうもない（Chuukyuu I L3） | vahva kielteinen ennuste | ミーティングはまだ終わり**そうもありません**。／9時までに帰れ**そうもない**。 |

## Nyanssi ja rajoitukset
- ⚠ Epäsäännölliset muodot: いい → **よさそう** (ei ×いそう), ない → **なさそう** (ei ×なそう). Molemmat on opeteltava erikseen.
- そうな+N ja そうに+V/adj noudattavat samaa vartalologiikkaa kuin そうです — そうな määrittää tulevaa substantiivia (怖そうな犬), そうに määrittää tulevaa verbiä/adjektiivia (楽しそうに歌う).
- そうもない (tai そうにない) on vahvempi kielteinen ennuste kuin pelkkä なさそう — ilmaisee ettei tapahtuma näytä toteutuvan lainkaan annetuissa olosuhteissa: ミーティングは終わりそうもありません (kokous ei näytä loppuvan mitenkään).
- Tunnetta ilmaisevat adjektiivit (うれしい、悲しい、寂しい) käyttävät そうです:ää aina kun kuvataan **toisen** tunnetta, koska omaa tunnetta ei tarvitse päätellä ulkonäöstä: ミラーさんはうれしそうです (Miller näyttää iloiselta) — ei koskaan わたしはうれしそうです omasta tunteesta.
- Verbimuodossa そうです viittaa nimenomaan **tulevaan, juuri alkamaisillaan olevaan** tapahtumaan, usein yhdessä 今にも/もうすぐ-adverbien kanssa.

## Sekaannusvaara
- Ks. [[普通形そうです (kuulopuhe)]] (Luku 47): サラリーマンだそうです (kuulopuhe, "kuulemma") ei ole sama kielioppi kuin tämä ulkonäköpäättely — kuulopuhe-そうです liittyy suoraan koko 普通形-lauseeseen ilman vartalomuutosta, ulkonäkö-そうです vaatii vartalon.

## Kortit
#flashcards/grammar/n4

今度の課長、頭が＿＿＿＿＿だし、まじめ＿＿＿＿ですね。(いい, まじめ)
?
よさそう, まじめそう — いい→よさそう on epäsäännöllinen; まじめ (な-adj) + そう on säännöllinen.

Miksi わたしはうれしそうです kuulostaa oudolta?
?
そうです ilmaisee ulkonäöstä pääteltyä asiaa — omaa tunnetta ei tarvitse päätellä ulkonäöstä, joten sitä ei käytetä ensimmäisestä persoonasta tunneadjektiiveilla.

#flashcards/grammar/n4/muodostus

V・adjそうです + verbi (ます-vartalo) :: V(ます-vartalo) + そうです, tapahtuma on juuri alkamaisillaan. Esim. 今にも雨が降りそうです.
V・adjそうです + い-adjektiivi :: い-adj (い pois) + そうです, näyttää siltä. Esim. おいしそうですね.
V・adjそうです + な-adjektiivi :: な-adj + そうです. Esim. まじめそうですね.
そう + substantiivin määrite (そうな + N) :: そう + な + N. Esim. 怖そうな犬ですね.
そう + verbin/adjektiivin määrite (そうに + V/adj) :: そう + に + V/adj. Esim. 楽しそうに歌っています.
V・adjそうです + kielteinen ulkonäkö :: ない → なさそう. Esim. 楽しくなさそうだね.
V(ます-vartalo)＋そうもない :: Vます-vartalo + そうもない: vahva kielteinen ennuste. Esim. ミーティングはまだ終わりそうもありません.

#flashcards/grammar/n4/nyanssi

Mitkä ovat V・adjそうです -rakenteen epäsäännölliset muodot い-adjektiiveilla いい ja ない?
?
いい → よさそう (ei いそう), ない → なさそう (ei なそう).

Miten そうもない eroaa pelkästä なさそう (V・adjそうです)?
?
そうもない on vahvempi kielteinen ennuste: tapahtuma ei näytä toteutuvan lainkaan annetuissa olosuhteissa.

Kenen tunteesta V・adjそうです voidaan käyttää tunneadjektiivien (うれしい, 悲しい) kanssa?
?
Toisen henkilön tunteesta (ミラーさんはうれしそうです); omaa tunnetta ei tarvitse päätellä ulkonäöstä.

Mihin aikaan viittaa verbi + そうです?
?
Tulevaan, juuri alkamaisillaan olevaan tapahtumaan, usein 今にも/もうすぐ-adverbien kanssa.

#flashcards/grammar/n4/sekaannus

Miten ulkonäkö-そうです eroaa kuulopuhe-そうです:sta (普通形そうです)?
?
Ulkonäkö-そうです liitetään vartaloon; kuulopuhe-そうです liittyy suoraan koko 普通形-lauseeseen (サラリーマンだそうです, 'kuulemma').
