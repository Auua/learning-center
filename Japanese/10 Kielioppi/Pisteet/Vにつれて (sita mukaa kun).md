> [!abstract] Ydin
> につれて kuvaa kahta **rinnakkain, asteittain etenevää** muutosta — "sitä mukaa kun X etenee, myös Y etenee". Molemmat muutokset ovat luonnollisia/vähittäisiä, ei kertaluontoisia.

## Merkitys
- **FI:** sitä mukaa kun, samassa tahdissa kuin
- **EN:** as, in proportion to (gradual parallel change)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V辞書形（ている） + につれて | 地球環境を制御するシステムの理解が深まる**につれて**、無数の解決策が見えてくるであろう。 |
| | 日本語が分かってくる**につれて**、日本での生活が楽しくなった。 |
| | 時間が経つ**につれて**、腹が立ってきた。 |
| N + の + につれて | ケータイなどの機器が普及する**につれて**、人間関係が変わってきた。 |

## Nyanssi ja rajoitukset
- Molemmat puolet kuvaavat **vähittäistä, jatkuvaa** muutosta — ei sovi kertaluontoisiin tapahtumiin.
- Jälkilause päättyy usein 〜てくる/〜ていく-muotoon korostamaan asteittaisuutta.

## Sekaannusvaara
- [[Vば〜ほど (mita enemman, sita)]]: molemmat kuvaavat verrannollista muutosta, mutta ば〜ほど vaatii saman verbin/adjektiivin toistoa hypoteettisessa muodossa; につれて kuvaa kahta **eri** ilmiötä jotka etenevät rinnakkain ajassa, ei ehtorakenteena.

## Kortit
#flashcards/grammar/n2

日本語が分かってくる＿＿＿＿、日本での生活が楽しくなった。(rinnakkainen asteittainen muutos)
?
につれて — "sitä mukaa kun", kaksi rinnakkaista vähittäistä muutosta.

#flashcards/grammar/n2/muodostus

V辞書形／Nの＋につれて + verbi :: V辞書形(ている) + につれて. 例: 時間が経つにつれて、腹が立ってきた。
V辞書形／Nの＋につれて + substantiivi :: N + の + につれて. 例: ケータイなどの機器が普及するにつれて、人間関係が変わってきた。

#flashcards/grammar/n2/nyanssi

Millaisia muutoksia V辞書形／Nの＋につれて yhdistää?
?
Vähittäisiä, jatkuvia muutoksia molemmissa puolissa; ei sovi kertaluontoisiin tapahtumiin.

Millaiseen muotoon V辞書形／Nの＋につれて-lauseen jälkilause usein päättyy?
?
〜てくる/〜ていく, mikä korostaa asteittaisuutta.

#flashcards/grammar/n2/sekaannus

Miten Vにつれて eroaa muodosta Vば〜ほど?
?
ば〜ほど toistaa saman sanan hypoteettisessa muodossa; につれて yhdistää kaksi eri ilmiötä, jotka etenevät rinnakkain ajassa, eikä ole ehtorakenne.
