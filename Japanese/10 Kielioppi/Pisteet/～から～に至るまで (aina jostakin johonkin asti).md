> [!abstract] Ydin
> から〜に至るまで korostaa kahden ääripään väliin mahtuvan **täydellisen kattavuuden** — "aina X:stä Y:hyn asti, kaikki siihen väliin mahtuva mukaan lukien". Vahvempi kuin にかけて.

## Merkitys
- **FI:** aina jostakin johonkin asti (täydellinen kattavuus)
- **EN:** from X all the way to Y, ranging from X to Y

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N1から、N2に至るまで | 上は宗教から、芸術から、生活**に至るまで**、型にはまってないものは一つとしてありません。 |
| | 自転車のねじから人工衛星の部品**に至るまで**、どれもこの工場で作っています。 |
| | クラシックからJ-pop**に至るまで**、当店ではどんなジャンルの音楽でもご用意しております。 |
| | この歌は子どもからお年寄り**に至るまで**、みんなに親しまれています。 |

## Nyanssi ja rajoitukset
- Korostaa **täydellistä, poikkeuksetonta** kattavuutta kahden ääripään välillä — usein käytetään liioittelevasti vaikutuksen tehostamiseksi.
- Muodollisempi ja voimakkaampi kuin [[～から～にかけて (jostakin johonkin, vali)]], joka viittaa epätarkkaan aika-/paikkaväliin ilman täydellisyyden korostusta.

## Sekaannusvaara
- [[～から～にかけて (jostakin johonkin, vali)]]: にかけて viittaa epätarkkaan ajan/paikan väliin (usein sää/tapahtumat); に至るまで korostaa täydellistä, poikkeuksetonta kattavuutta kategorioiden tai esineiden välillä.
