> [!abstract] Ydin
> ように ilmaisee tavoitteen: "jotta ~ tapahtuisi/onnistuisi". Toisin kuin tahdonalaisten verbien ため(に), ように käytetään **ei-tahdonalaisten** (potentiaali-, tila- tai kielto-)verbien kanssa.

## Merkitys
- **FI:** jotta, niin että
- **EN:** so that, in order that

## Muodostus
| Kaava | Esimerkki |
|---|---|
| [[Potentiaali える]] + ように | 速く**泳げるように**、毎日練習しています。 |
| | 知らないことばを聞いたら、すぐ**調べられるように**、持っているんです。 |
| [[ない-muoto]] + ように | **忘れないように**、つけてあるんです。 |
| | 絶対に**遅れないように**して ください。 |
| Ei-tahdonalainen V(辞書形) + ように | 後ろの人にもよく**聞こえるように**、大きな声で話してください。 |
| | 風邪が早く**治るように**、薬を飲んで寝た。 |
| Tahdonalainen V（ない形） + ように | **食べすぎないように**、小さいお皿を使っています。 |
| Eri subjekti + V + ように | 学生がメモを**取れるように**、先生はゆっくり話した。 |

Käytetyt taivutusmuodot: [[Potentiaali える]] (kyky: 話せる, 読める), [[Sanakirjamuoto]] vain ei-tahdonalaisilla verbeillä (見える, 聞こえる, わかる, 治る, なる), [[ない-muoto]] kaikilla verbeillä.

## Nyanssi ja rajoitukset
- Käytetään ei-tahdonalaisten verbien kanssa (potentiaali, kielto, tilaverbit kuten わかる, 見える) — tahdonalaisille verbeille käytetään ため(に): 会うために行きます (ei ×会うように).
- **Perusmuoto vai potentiaali?** Valinta riippuu verbistä, ei merkityksestä: tahdonalainen verbi (話す, 読む) muutetaan potentiaaliksi (話せる, 読める), jotta siitä tulee ei-tahdonalainen tila. Valmiiksi ei-tahdonalainen verbi (見える, 聞こえる, わかる, 治る) jää perusmuotoon: ×わかれるように → ○わかるように.
- **ない形 käy myös tahdonalaisille verbeille**: 食べすぎないように, 忘れないように, 遅れないように. Kielto kuvaa tilaa, jota halutaan välttää.
- **Eri subjekti** sivulauseessa sopii ように:lle (学生がメモを取れるように、先生はゆっくり話した); ため(に) vaatii yleensä saman subjektin.
- ように…してください on [[Vようにする・ようにしてください (huolehtia etta)]] -rakenne: "huolehtikaa siitä, että...".

## Sekaannusvaara
- ため(に) sopii tahdonalaiselle päätavoitteelle (日本語を勉強するために日本へ来ました); ように sopii ei-tahdonalaiselle kyvylle/tilalle (日本語が話せるように毎日勉強しています) — verbin tahdonalaisuus ratkaisee valinnan.
- Kaikki ように-rakenteet rinnakkain: [[Vertailu — ように-rakenteet]].
- ⚠ Sama kirjoitusasu ように esiintyy myös [[普通形ようです (havaintoon perustuva paattely)]]:n (Luku 47) osana, mutta se on täysin eri kielioppi (havaintoon perustuva päättely, ei tarkoitus) — erottaa lauserakenteesta: tämä ように jatkuu toisella verbillä/lauseella, päättely-ようです päättää lauseen.

## Kortit
#flashcards/grammar/n4

速く＿＿＿＿＿＿、毎日練習しています。(泳ぐ, potentiaali)
?
泳げるように — potentiaali + ように, ei-tahdonalainen tavoite.

Miksi ei sanota ×日本語が話せるために?
?
ため(に) vaatii tahdonalaisen verbin; 話せる on potentiaali (ei-tahdonalainen) — siksi ように, ei ため(に).

後ろの人にもよく聞こえる＿＿＿、大きな声で話してください。(聞こえる, jotta kuuluisi)
?
ように — 聞こえる on valmiiksi ei-tahdonalainen, joten se jää perusmuotoon (×聞こえられる).

#flashcards/grammar/n4/muodostus

V(potentiaali/ei-tahdonalainen)ように + potentiaali :: Potentiaali + ように. 例: 速く泳げるように、毎日練習しています。
V(potentiaali/ei-tahdonalainen)ように + kielto :: ない-muoto + ように. 例: 忘れないように、つけてあるんです。
V(potentiaali/ei-tahdonalainen)ように + ei-tahdonalainen perusmuoto :: 見える／聞こえる／わかる／治る + ように. 例: 後ろの人にも聞こえるように話す。

#flashcards/grammar/n4/nyanssi

Minkä verbien kanssa ように käytetään tarkoitusta ilmaistaessa?
?
Ei-tahdonalaisten (potentiaali, kielto, tilaverbit kuten わかる, 見える); tahdonalaisille käytetään ため(に): 会うために行きます.

Milloin ように-lauseen verbi on perusmuodossa, milloin potentiaalissa?
?
Tahdonalainen verbi muutetaan potentiaaliksi (話す → 話せるように); valmiiksi ei-tahdonalainen verbi jää perusmuotoon (見えるように, わかるように).

Voiko tahdonalainen verbi olla ように-lauseessa kieltomuodossa?
?
Voi: 食べすぎないように, 忘れないように — kielto kuvaa vältettävää tilaa.

Mitä tarkoittaa rakenne ように…してください?
?
Yleinen kohtelias pyyntömuoto: 'pyrkikää siihen että...' (絶対に遅れないようにしてください).

#flashcards/grammar/n4/sekaannus

日本語が話せる（ため／よう）に、毎日勉強しています。Kumpi?
?
Verbin tahdonalaisuus ratkaisee: ため(に) tahdonalaiselle päätavoitteelle (日本語を勉強するために日本へ来ました); ように ei-tahdonalaiselle kyvylle/tilalle (日本語が話せるように毎日勉強しています).

Miten tarkoitus-ように erotetaan ようです-päättelystä?
?
Sama kirjoitusasu, eri kielioppi: tarkoitus-ように jatkuu toisella verbillä/lauseella, päättely-ようです päättää lauseen.
