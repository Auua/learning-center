> [!abstract] Ydin
> で lukumäärän perässä kertoo, **millä kokoonpanolla, määrällä, ajalla tai hinnalla** teko tehdään: kuinka monen hengen voimin, kuinka paljon yhteensä, missä ajassa.

## Merkitys
- **FI:** (yksin, kolmestaan); yhteensä; (tunnissa); (hintaan)
- **EN:** by oneself / as a group of; in total; within (time); for (price)

## Muodostus
| Käyttö | Kaava | Esimerkki |
|---|---|---|
| Ryhmän koko | 人数 + で | [[一人]]**で**作りました。／[[三人]]**で**旅行しました。 |
| Yhteismäärä | 数量 + で | [[全部で]]3,000円です。 |
| Aika, jossa jotain tehdään | 時間 + で | 1時間**で**終わりました。 |
| Hinta | 金額 + で | 500円**で**買いました。 |
| Raja (koko) | N + で | このクラスは20人**で**いっぱいです。 |

## Nyanssi ja rajoitukset
- **一人で vs. 一人と:** 一人で = yksin (tekijöitä yksi); と tarvitsee aina seuralaisen: 友だち**と**二人**で**行きました (menin kahdestaan ystävän kanssa). Molemmat voivat esiintyä samassa lauseessa.
- **みんなで** = kaikki yhdessä (ryhmä), mutta みんなが = kaikki (jokainen tekijänä).
- **Aika で vs. に:** 1時間**で**読んだ (lukemiseen kului tunti) vs. 3時**に**読んだ (kellonaika).
- Hinta-で on [[N (väline) で]]:n sukulainen (raha välineenä), mutta tämä note kokoaa määrän ja ryhmän käytöt yhteen.

## Sekaannusvaara
- 一人**で**行きました（yksin）vs. 一人**が**行きました（yksi henkilö meni, muut eivät）.
- 全部**で**いくらですか（yhteensä）vs. 全部**を**買いました（kaiken, objekti）.

#flashcards/grammar/n4/muodostus

N（人数・数量・時間・金額）で + henkilömäärä :: 人数 + で. Esim. 三人で旅行しました。
N（人数・数量・時間・金額）で + yhteismäärä :: 数量 + で. Esim. 全部で3,000円です。
N（人数・数量・時間・金額）で + aika :: 時間 + で (aika jossa tehdään). Esim. 1時間で終わりました。
N（人数・数量・時間・金額）で + hinta :: 金額 + で. Esim. 500円で買いました。

#flashcards/grammar/n4/nyanssi

Miten 一人で eroaa と-seuralaisesta N（人数・数量・時間・金額）で -rakenteessa?
?
一人で = yksin; と tarvitsee aina seuralaisen. Voivat olla samassa lauseessa: 友だちと二人で行きました。

Miten みんなで eroaa みんなが:sta?
?
みんなで = kaikki yhdessä ryhmänä; みんなが = kaikki jokainen tekijänä.

Miten aika-で eroaa kellonaika-に:stä?
?
1時間で読んだ = lukemiseen kului tunti; 3時に読んだ = luettiin kello kolmelta.

#flashcards/grammar/n4/sekaannus

Miten 一人で行きました eroaa lauseesta 一人が行きました?
?
一人で = yksin (tekijä yksi); 一人が = yksi henkilö meni, muut eivät.

Miten 全部でいくらですか eroaa lauseesta 全部を買いました?
?
全部で = yhteensä (määrä); 全部を = kaiken (objekti).
