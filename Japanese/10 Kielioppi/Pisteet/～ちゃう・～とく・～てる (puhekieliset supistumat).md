> [!abstract] Ydin
> Kolme yleisintä puhekielistä supistumaa: てしまう→ちゃう, ておく→とく, ている→てる. Merkitys pysyy täsmälleen samana kuin täydellä muodolla — vain ääntäminen lyhenee luontevaksi arkipuheeksi.

## Merkitys
- **ちゃう (FI):** = [[Vてしまいます (valitettavasti, loppuun asti)]] lyhyesti
- **とく (FI):** = [[Vておきます (valmistelu etukateen)]] lyhyesti
- **てる (FI):** = [[～ている (parhaillaan, tilan tulos)]] lyhyesti

## Muodostus
| Täysi muoto | Supistuma | Esimerkki |
|---|---|---|
| てしまう | ちゃう | 目が覚めて**しまった** → 目が覚め**ちゃった** |
| でしまう | じゃう | 飲んで**しまう** → 飲ん**じゃう** |
| ておく | とく | つけて**おいて** → つけ**といて** |
| でおく | どく | 読んで**おく** → 読ん**どく** |
| ている | てる | 続けて**いる** → 続け**てる** |
| でいる | でる | 死んで**いる** → 死ん**でる** |

## Nyanssi ja rajoitukset
- Supistumasääntö riippuu siitä oliko alkuperäinen て-muoto て vai で: て→ちゃう/とく/てる; で→じゃう/どく/でる (ääntämisen mukaisesti soinnillistuu).
- Nämä ovat **puhtaasti puhekielisiä** — eivät koskaan kirjoitettuun tekstiin tai muodolliseen puheeseen.
- Kysymyksiin ja lyhyisiin vastauksiin erittäin yleisiä: 続けてる？……うん、続けてるよ。／もう読んだ？……ううん、まだ読んでない。

## Sekaannusvaara
- Älä käytä näitä muodollisissa/kirjallisissa yhteyksissä — vrt. tämän saman luvun [[～である (kirjallinen kopula)]], joka edustaa päinvastaista, muodollista rekisteriä.

#flashcards/grammar/n3

エアコン、消そうか？……ううん、そのままつけ＿＿＿＿。(ておく, puhekielinen)
?
といて — ておいて → といて, puhekielinen supistuma.

Miksi 飲んでしまう supistuu muotoon 飲んじゃう eikä 飲んちゃう?
?
でしまう-yhdistelmä soinnillistuu じゃう:ksi (で→じ), koska alkuperäinen oli で- ei て-muotoinen.

#flashcards/grammar/n3/muodostus

てしまう／でしまう → supistuma :: てしまう → ちゃう, でしまう → じゃう — esim. 目が覚めてしまった → 目が覚めちゃった／飲んでしまう → 飲んじゃう
ておく／でおく → supistuma :: ておく → とく, でおく → どく — esim. つけておいて → つけといて／読んでおく → 読んどく
ている／でいる → supistuma :: ている → てる, でいる → でる — esim. 続けている → 続けてる／死んでいる → 死んでる

#flashcards/grammar/n3/nyanssi

Mistä riippuu, tuleeko ちゃう・とく・てる -supistumassa ちゃう vai じゃう (とく/どく, てる/でる)?
?
Alkuperäisestä て-muodosta: て → ちゃう/とく/てる; で → じゃう/どく/でる.

Voiko ちゃう・とく・てる -supistumia käyttää kirjoitetussa tekstissä?
?
Ei: ne ovat puhtaasti puhekielisiä, eivät sovi kirjalliseen tai muodolliseen kieleen; merkitys on sama kuin täydellä muodolla.
