> [!abstract] Ydin
> Tavallisimmilla verbeillä on oma **erillinen kunnioittava verbi**, jota käytetään お～になる-muodon sijaan: 行く/来る/いる → いらっしゃる, 食べる/飲む → 召し上がる, 言う → おっしゃる, する → なさる, 見る → ご覧になる, 知っている → ご存じだ, くれる → くださる.

## Merkitys
- **FI:** (hän) menee / tulee / on / syö / sanoo / tekee / katsoo / tietää — kunnioittavasti
- **EN:** special honorific verbs

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 行く・来る・いる → いらっしゃる | 社長は会議室に**いらっしゃいます**。 |
| 食べる・飲む → 召し上がる | 何を**召し上がります**か。 |
| 言う → おっしゃる | 先生が**おっしゃいました**。 |
| する → なさる／見る → ご覧になる | 週末は何を**なさいます**か。 |
| 知っている → ご存じだ／くれる → くださる | この本を**ご存じです**か。 |

## Nyanssi ja rajoitukset
- いらっしゃる, おっしゃる, なさる, くださる taipuvat ます-muodossa epäsäännöllisesti: いらっしゃ**い**ます (ei ×いらっしゃります).
- Käskymuoto pyynnöissä: いらっしゃい, おっしゃってください, ご覧ください, 召し上がってください.
- Erityisverbin olemassa ollessa ei käytetä お～になる-muotoa: ×お行きになる → ○いらっしゃる.

## Sekaannusvaara
- いらっしゃる (kunnioittava: toinen menee/tulee/on) vs. 参る／おる (nöyrä: minä menen/olen).
- ×いらっしゃります → ○いらっしゃいます.
