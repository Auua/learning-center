> [!abstract] Ydin
> ようになります kuvaa **asteittaista muutosta**. Potentiaalin kanssa muuttuu **kyky** (泳げるようになった = opin uimaan), perusmuodon kanssa **tapa tai tila** (泳ぐようになった = aloin uida). Muutos tapahtuu tilaan/kykyyn — "en osannut/tapahtunut ennen, mutta nyt kylläkin (harjoittelun/ajan myötä)". Kielteinen ～なくなりました kertoo päinvastaisesta muutoksesta.

## Merkitys
- **FI:** tulla sellaiseksi että (pystyy/tapahtuu), oppia vähitellen
- **EN:** to come to (be able to), to reach the point where

## Muodostus
| Kaava | Esimerkki |
|---|---|
| [[Potentiaali える]] + ようになりました | やっと自転車に**乗れるようになりました**。 |
| | 最近タンゴが**踊れるようになりました**。 |
| [[Potentiaali える]]（kielto）+ なくなりました | 工場ができてから、この近くの海では**泳げなくなりました**。 |
| ようになりたいです（toive） | 早く**弾けるようになりたいです**。 |
| V(辞書形) + ようになりました（tapa/käytös muuttui） | 日本でもハロウィンを**楽しむようになった**。 |
| | 毎朝プールで**泳ぐようになって**から、体の調子がいい。 |
| Ei-tahdonalainen V(辞書形) + ようになる（tila/kyky） | 眼鏡をかけたら、黒板の字がよく**見えるようになった**。 |
| V(辞書形)（kielto） + なくなりました | スマホを買ってから、あまり本を**読まなくなった**。 |

Käytetyt taivutusmuodot: [[Potentiaali える]] = kyvyn muutos; [[Sanakirjamuoto]] = tavan, käytöksen tai ei-tahdonalaisen tilan muutos (見える, わかる); kielto ilmaistaan yleensä muodolla 〜なくなる.

## Nyanssi ja rajoitukset
- **Potentiaali vai perusmuoto?** 泳げるようになった = opin uimaan (kyky syntyi). 泳ぐようになった = aloin uida (toiminta tuli tavaksi; kyky oli jo ennestään). Samoin 日本語が話せるようになった (opin puhumaan) vs. 日本語で話すようになった (aloin puhua japaniksi).
- Valmiiksi ei-tahdonalaiset verbit (見える, 聞こえる, わかる) ilmaisevat kyvyn tai tilan perusmuodossa: 見えるようになった (×見えられる).
- Perusmuoto + ようになる kuvaa usein myös ihmisryhmän tai yhteiskunnan muutosta: 若者も着物を着るようになった.
- Kielteinen muutos ilmaistaan tavallisimmin muodolla 〜なくなる (読まなくなった, 泳げなくなった); 〜ないようになる on harvinaisempi.
- Korostaa **prosessia/ajan kulumista**, ei äkillistä muutosta — sopii harjoittelun tai totuttelun tulokseen, ei kertaluonteiseen tapahtumaan.
- ～なくなりました on tärkeä kielteinen vastapari: kuvaa kyvyn/mahdollisuuden **häviämistä** ajan myötä (esim. ympäristön muuttuessa): 泳げなくなりました ("ei voi enää uida siellä", ei "ei osannut koskaan").
- Ei pidä sekoittaa [[Vように (jotta, niin etta)]]:iin — ように ilmaisee tavoitteen, ようになります kertoo jo tapahtuneen/tapahtuvan muutoksen.

## Sekaannusvaara
- 泳げるようになった (opin uimaan — kyky) vs. 泳ぐようになった (aloin uida säännöllisesti — tapa).
- 泳ぐようになった (aloin uida — muutos tapahtui) vs. 泳ぐようにしている (pyrin uimaan — tietoinen yritys, [[Vようにしています (tavakseen pyrkiminen)]]).
- Kaikki ように-rakenteet rinnakkain: [[Vertailu — ように-rakenteet]].
- 泳げませんでした（ei koskaan osannut）vs. 泳げなくなりました（osasi ennen, mutta ei enää — muutos tapahtui）: jälkimmäinen vaatii aina jonkin syyn/muutoksen taustalla (esim. 工場ができてから).

最近、毎朝ジョギング＿＿＿＿＿＿＿＿。(する, aloin — tapa muuttui)
?
するようになりました — perusmuoto + ようになる = toiminnasta tuli tapa (ei kyvyn muutos).

#flashcards/grammar/n4/muodostus

V(potentiaali/普通形)ようになります + potentiaali :: Potentiaali + ようになりました. 例: やっと自転車に乗れるようになりました。
V(potentiaali/普通形)ようになります + kielto :: Potentiaali (kielto) + なくなりました. 例: 泳げなくなりました。
V(potentiaali/普通形)ようになります + toive :: ようになりたいです. 例: 早く弾けるようになりたいです。
V(potentiaali/普通形)ようになります + perusmuoto :: V辞書形 + ようになりました (tapa muuttui). 例: 日本でもハロウィンを楽しむようになった。
V(potentiaali/普通形)ようになります + ei-tahdonalainen :: 見える／わかる + ようになる. 例: 黒板の字がよく見えるようになった。

#flashcards/grammar/n4/nyanssi

Millaista muutosta ようになります kuvaa?
?
Asteittaista muutosta, prosessia ja ajan kulumista (harjoittelun tai totuttelun tulos); ei äkillistä kertaluonteista muutosta.

Mitä ～なくなりました ilmaisee rakenteen ようになります kielteisenä vastaparina?
?
Kyvyn tai mahdollisuuden häviämistä ajan myötä, esim. ympäristön muuttuessa: 泳げなくなりました ('ei voi enää uida siellä').

Mikä ero on muodoilla 泳げるようになった ja 泳ぐようになった?
?
泳げる (potentiaali) = opin uimaan, kyky syntyi; 泳ぐ (perusmuoto) = aloin uida säännöllisesti, toiminnasta tuli tapa.

Miksi sanotaan 見えるようになった eikä ×見えられるようになった?
?
見える on jo valmiiksi ei-tahdonalainen (kyky/tila), joten se ei tarvitse potentiaalia.

#flashcards/grammar/n4/sekaannus

泳ぐようになった vs. 泳ぐようにしている?
?
ようになった = muutos on tapahtunut (tulos); ようにしている = tietoinen pyrkimys ylläpitää tapaa.

Miten ようになります eroaa muodosta ように (tavoite)?
?
ように ilmaisee tavoitteen ('jotta'); ようになります kertoo jo tapahtuneen tai tapahtuvan muutoksen.

Miten 泳げませんでした ja 泳げなくなりました eroavat?
?
泳げませんでした: ei koskaan osannut. 泳げなくなりました: osasi ennen, mutta ei enää; muutos vaatii aina taustalla syyn (esim. 工場ができてから).
