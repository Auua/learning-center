> [!abstract] Ydin
> Molemmat korostavat voimakkaasti, mutta eri tunteella: なんか **vähättelee** puhuttua asiaa (usein itsestä tai jostain vähäpätöisestä); なんて ilmaisee **yllätystä/järkytystä** jostain uskomattomasta.

## Merkitys
- **なんか (FI):** tuollainen, semmoinen (vähättelevä sävy)
- **なんて (FI):** ties mikä, mokoma (yllättynyt/järkyttynyt sävy)

## Muodostus
| Kaava | Sävy | Esimerkki |
|---|---|---|
| N + なんか + kielteinen/vähättelevä lause | vähättely (usein itsestä) | え？わたし**なんか**だめですよ。ほかにいい人がいますよ。 |
| N + なんか + いらない | jonkin vähättely | お金**なんか**要らないわ。あなたといっしょにいるだけでいいの。 |
| N + なんか + 気にしない(で) | neuvo olla välittämättä | 点数**なんか**気にしないで。たいしたことじゃないよ。 |
| 普通形 + なんて + 信じられない/知らなかった | yllätys/järkytys | 彼が医者になる**なんて**信じられない。 |
| | | ミラーさんがこんなに歌がうまい**なんて**知らなかった。 |

## Nyanssi ja rajoitukset
- なんか seuraa aina substantiivia ja vähättelee sen arvoa/merkitystä — usein käytetään vaatimattomuuden ilmaisuun itsestä (わたしなんか) tai lohduttamiseen (お金なんか気にしないで).
- なんて voi seurata sekä substantiivia että kokonaista lausetta (普通形) — ilmaisee aina voimakasta yllätystä, usein negatiivisesti värittynyttä epäuskoa.
- Molemmat ovat puhekielisiä, tunnepitoisia korostuskeinoja — ei sovi muodolliseen tekstiin.

## Sekaannusvaara
- なんか vähättelee (arvo on pieni/merkityksetön); なんて yllättyy (asia on uskomaton/järkyttävä) — vastakkaiset tunnesävyt vaikka molemmat ovat voimakkaita korostuskeinoja.
