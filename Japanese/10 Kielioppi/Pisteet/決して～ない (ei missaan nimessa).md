> [!abstract] Ydin
> 決して vahvistaa kieltoa ehdottomaksi — "ei missään nimessä/tapauksessa". Vaatii aina kielteisen predikaatin lauseen lopussa.

## Merkitys
- **FI:** ei missään nimessä, ei ollenkaan (ehdoton kielto)
- **EN:** never, by no means (absolute negation)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 決して + 普通形（ない） | 演劇は**決して**華やかなだけの世界ではないということを覚えておいてほしい。 |
| | 経営者側は自分たちの責任を**決して**認めようとはしなかった。 |
| | 落とした財布が中身ごと戻ってくるということは**決して**めずらしくない。 |
| | 野球は世界的には**決して**ポピュラーなスポーツとは言えない。 |

## Nyanssi ja rajoitukset
- ⚠ 決して vaatii AINA kielteisen loppupredikaatin (ではない, 〜ようとしない, 〜とは言えない) — ei koskaan myönteisen lauseen kanssa.
- Vahvempi kuin pelkkä ない — sulkee pois kaikki poikkeukset ehdottomasti.
