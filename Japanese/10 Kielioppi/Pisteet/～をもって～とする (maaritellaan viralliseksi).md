> [!abstract] Ydin
> をもって〜とする on erittäin muodollinen ilmaus, jolla jokin väline/kriteeri **määritellään viralliseksi mittariksi tai päätökseksi** — "N:n perusteella/kautta määritellään N2:ksi".

## Merkitys
- **FI:** N:n perusteella/välityksellä määritellään, virallinen kriteerinä
- **EN:** by means of N, it is determined/regarded as N2 (formal)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + をもって + N2とされる/とする | それ**をもって**「客観的評価」**とされている**。 |
| | 出席率、授業中の発表、レポート**をもって**、評価**とします**。 |
| | 拍手**をもって**、賛成をいただいたもの**といたします**。 |
| | 日本では、運転免許証**をもって**身分証明書**とする**場合がある。 |

## Nyanssi ja rajoitukset
- Erittäin muodollinen — tyypillinen virallisissa säännöissä, kokouksissa ja hallinnollisissa päätöksissä.
- Väline (N) toimii virallisena perustana/kriteerinä jolle jokin status/päätös rakentuu.
