> [!abstract] Ydin
> Looginen ehto: painopiste on siinä **mitä vaaditaan**, jotta B toteutuu. Sananlaskujen ja hypoteesien muoto.

## Merkitys
- **FI:** jos (vain siinä tapauksessa että)
- **EN:** if / provided that

## Muodostus
Ks. [[Ehtomuoto ば]].

| Mihin liittyy | Kaava | Esimerkki |
|---|---|---|
| Verbi | え-rivi + ば | 書く → 書けば、食べる → 食べれば |
| い-adjektiivi | い → ければ | 安い → 安ければ |
| な-adjektiivi / subst. | + なら(ば) | 便利 → 便利なら(ば) |
| Kielto | ない → なければ | 行かない → 行かなければ |

Käytetyt taivutusmuodot: [[Ehtomuoto ば]]

## Nyanssi ja rajoitukset
- **Jälkilauseessa ei saa olla käskyä, pyyntöä tai kutsua**, jos etulause on tahdonalainen toimintaverbi. Käytä silloin [[～たら (jos, kun)]].
- Poikkeus: kun etulause on tilaverbi tai adjektiivi, pyyntö käy: 時間があれば、手伝ってください。
- Tyypilliset kaavat: ～ば～ほど (mitä enemmän… sitä…), ～ばよかった (olisipa…), ～さえ～ば (kunhan vain…).
- **Kontrafaktuaalinen käyttö (Chuukyuu I Luku 9):** kun jälkilause on menneessä ajassa (〜んですが), ば+た-lause kuvaa mitä olisi tapahtunut jos ehto olisi täyttynyt: もう少し安**ければ**、**買ったんですが**（…mutta en ostanut, koska ei ollut riittävän halpa）. Ks. [[Vertailu — たら・ば + ta (kontrafaktuaalinen)]].

## Kortit
#flashcards/grammar/n4

ば — mikä on pääasiallinen rajoitus?
?
Jälkilauseessa ei käsky/pyyntö/kutsu, jos etulause on tahdonalainen toimintaverbi. Tilaverbi tai adjektiivi etulauseessa poistaa rajoituksen (時間があれば、手伝ってください).

#flashcards/grammar/n4/muodostus

～ば + verbi :: え-rivi + ば. Esim. 書く → 書けば、食べる → 食べれば
～ば + い-adjektiivi :: い → ければ. Esim. 安い → 安ければ
～ば + な-adjektiivi／substantiivi :: + なら(ば). Esim. 便利 → 便利なら(ば)
～ば + kielteinen muoto :: ない → なければ. Esim. 行かない → 行かなければ
