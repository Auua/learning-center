> [!abstract] Ydin
> Erikoisryhmä sanoja — 好き／嫌い／上手／下手 (な-adjektiiveja) sekä わかります／あります (verbejä) — merkitsee kohteensa **が**:lla, ei を:lla, vaikka suomeksi ajattelisi niitä "objektillisina". Yhteinen nimittäjä: mieltymys, kyky, ymmärrys tai omistus.

## Merkitys
- **FI:** pitää X:stä / olla taitava X:ssä / ymmärtää X / olla X (omistus)
- **EN:** to like X / to be good at X / to understand X / to have X

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N が 好き／嫌いです | イタリア料理**が**好きです。 |
| N が 上手／下手です | 絵が上手です。 |
| N が わかります | 日本語**が**わかります。 |
| N が あります | 車**が**あります。 |

## Nyanssi ja rajoitukset
- Näissä sanoissa "kohde" ei ole tekemisen suora objekti (kuten を:lla merkityissä), vaan sen asian **aihe/lähde**, johon tunne/kyky/tieto kohdistuu — siksi partikkeli on eri.
- 上手/下手 kuuluvat vain **toisen** taidon arviointiin kohteliaassa puheessa — omasta taidosta kehuminen 上手です on epäkohteliasta; omasta puutteesta voi sanoa 下手です.

## Sekaannusvaara
Vertailu [[Nを V (objekti)]]: を merkitsee suoraa tekemisen kohdetta (テニス**を**します, itse pelaaminen), が merkitsee tunteen/kyvyn/tiedon kohdetta (テニス**が**好きです, pitäminen pelistä) — sama asia, kaksi eri näkökulmaa samaan sanaan.

## Kortit
#flashcards/grammar/n5

イタリア料理が好きです — miksi が, ei を?
?
好き on な-adjektiivi joka ilmaisee mieltymystä; sen kohde merkitään が:lla, ei を:lla (joka on vain transitiivisten verbien objektille).

上手です omasta taidosta — sopiiko?
?
Ei kohteliasta — 上手 on arvio jonka kuulija/kolmas antaa toisesta. Omasta osaamisesta kehuminen näin kuulostaa itsekehulta.

#flashcards/grammar/n5/muodostus

Nが好きです／上手です／わかります／あります + 好き／嫌い :: N が 好き／嫌いです. Esim. イタリア料理が好きです。
Nが好きです／上手です／わかります／あります + 上手／下手 :: N が 上手／下手です. Esim. 絵が上手です。
Nが好きです／上手です／わかります／あります + わかります :: N が わかります. Esim. 日本語がわかります。
Nが好きです／上手です／わかります／あります + あります (omistus) :: N が あります. Esim. 車があります。

#flashcards/grammar/n5/nyanssi

Miksi Nが好きです -rakenteessa kohde merkitään が:lla eikä を:lla?
?
Kohde ei ole tekemisen suora objekti vaan asian aihe tai lähde, johon tunne, kyky tai tieto kohdistuu.

Kenen taidosta Nが上手です voidaan kohteliaasti sanoa?
?
Toisen; omasta taidosta 上手です on epäkohteliasta kehumista, mutta omasta puutteesta voi sanoa 下手です.

#flashcards/grammar/n5/sekaannus

Miten テニスをします eroaa lauseesta テニスが好きです (を vs が)?
?
を merkitsee suoraa tekemisen kohdetta (itse pelaaminen); が merkitsee tunteen, kyvyn tai tiedon kohdetta (pitäminen pelistä).
