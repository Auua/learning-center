> [!abstract] Ydin
> Transitiiviverbi + てある kertoo että **joku teki tämän tarkoituksella etukäteen**, ja tulos on nähtävissä nyt. Vastapari [[自動詞＋ている (jaljelle jaanyt tila)]]:lle, joka ei ota kantaa tekijään.

## Merkitys
- **FI:** on (tarkoituksella) tehty, on valmiiksi laitettu
- **EN:** has been (deliberately) done/set up, is prepared

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 他動詞 (transitiivi) + てあります | 交番に町の地図が**はって**あります。 |
| | 壁に花や動物の絵が**かいて**あるんです。 |
| | あの引き出しに**しまって**ありますよ。 |
| | お子さんの名前はもう**決めて**ありますか。 |
| | ホワイトさんにはもう**連絡して**ありますか。 |

## Nyanssi ja rajoitukset
- Partikkeli on aina が, vaikka verbi on transitiivinen: 地図**が**はってあります (ei を) — koska huomio on tuloksena olevassa tilassa, ei tekijässä.
- Tekijää ei koskaan mainita てある-lauseessa; jos tekijä pitää mainita, käytetään tavallista transitiivilausetta (地図をはりました).
- Vertaa pariin: 窓が閉まっている（tila, ei kerro tekikö kukaan sen tarkoituksella）vs. 窓が閉めてある（joku sulki sen tarkoituksella valmiiksi）.

## Sekaannusvaara
- [[自動詞＋ている (jaljelle jaanyt tila)]] käyttää intransitiiviverbiä eikä ota kantaa tekijään (窓が閉まっている); てある käyttää transitiiviverbiä ja vihjaa aina tarkoituksellisuudesta (窓が閉めてある).
