> [!abstract] Ydin
> Tässä käytössä もの (eri kuin もの・もんだから:n syy-käyttö) ilmaisee **yleisen totuuden, luonnollisen taipumuksen tai moraalisen normin** — "asiat vain ovat/eivät ole niin", usein elämänviisautena.

## Merkitys
- **FI:** (asiat) ovat vain sellaisia, ei sovi tehdä (yleinen totuus/normi)
- **EN:** that's just how things are / one shouldn't (general truth or norm)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + ものだ（yleistotuus） | 人は変わる**ものだ**。 |
| | お金って、なかなか貯まらない**もんですね**。 |
| | 人の運命は分からない**ものだ**。 |
| 普通形 + ものではない（moraalinen kielto） | こんな幸運は人生の中でそう何度もある**ものではない**。 |
| | 日本語で日常的に使われる漢字は2000字以上ある。1年や2年で覚えられる**ものではない**。 |
| | 人の悪口を言う**ものではない**。 |
| もんじゃない（puhekielinen） | 身長のせいにする**もんじゃない**よ。 |

## Nyanssi ja rajoitukset
- Eroaa selvästi [[もの・もんだから (perusteleva syy)]]:sta: tässä もの ei liity syyhyn (ei だから-jatko), vaan päättää lauseen **yleistyksenä tai neuvona**.
- ものだ sopii sekä neutraaliin yleistykseen (人は変わるものだ) että nostalgiseen muisteluun (昔はよく〜したものだ, ei tässä luvussa mutta yleinen sukulaiskäyttö).
- ものではない/もんじゃない on lievä, yleispätevä moraalinen neuvo tai kielto — pehmeämpi kuin suora 〜してはいけない.

## Sekaannusvaara
- [[もの・もんだから (perusteleva syy)]]: もの/もんだから selittää/puolustelee jotain nimenomaista tapahtunutta asiaa syynä; tämän muistiinpanon ものだ/ものではない ei anna syytä vaan toteaa **yleisen totuuden tai normin**, eikä koskaan jatku だから:lla.
