> [!abstract] Ydin
> N + ぐるみ = **"koko N mukaan lukien, N:n kanssa yhdessä"** — 家族ぐるみ, 町ぐるみ, 会社ぐるみ.

## Merkitys
- **FI:** koko … yhdessä, mukaan lukien
- **EN:** whole, together with, including

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + ぐるみ + で | 家族**ぐるみ**で付き合う。 |
| N + ぐるみの + N | 会社**ぐるみの**不正 |

## Nyanssi ja rajoitukset
- Vakiintuneet: 家族ぐるみ, 町ぐるみ, 村ぐるみ, 会社ぐるみ, 組織ぐるみ.
- 会社ぐるみの不正 = koko yhtiön yhteinen vilppi (kielteinen).
