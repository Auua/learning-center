> [!abstract] Ydin
> いかに〜か on muodollinen/kirjallinen tapa kysyä tai korostaa **missä määrin/kuinka paljon** jokin pätee — vahvempi ja muodollisempi kuin どんなに.

## Merkitys
- **FI:** kuinka (paljon/suuresti), missä määrin (muodollinen)
- **EN:** how (much/greatly) — formal register

## Muodostus
| Kaava | Esimerkki |
|---|---|
| いかに + 普通形 + かがわかる/知った | 日本人が**いかに**水と密着して独自の水文化を築きあげてきた**か**がよくわかる。 |
| | 朝のラッシュを見ると、日本人が**いかに**我慢強い**か**がわかる。 |
| | 自然の力の前では人間の存在などが**いかに**小さなものだ**か**を知った。 |
| | 今までいかに無駄に電気を使っていたかに気づいた。 |

## Nyanssi ja rajoitukset
- Muodostaa upotetun kysymyslauseen (いかに〜か) joka toimii predikaatin (わかる, 知る, 気づく) objektina.
- Muodollisempi ja kirjallisempi kuin どんなに — sopii esseisiin, puheisiin, vakavaan pohdiskeluun.
