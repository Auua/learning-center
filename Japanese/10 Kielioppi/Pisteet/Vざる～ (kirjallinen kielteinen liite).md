> [!abstract] Ydin
> ざる on ず:n (kirjallinen kielto) adnominaalinen muoto — liittyy suoraan seuraavaan substantiiviin muodostaen kielteisen määritteen ("joka ei ole/tee X").

## Merkitys
- **FI:** joka ei ole, ~ton (kirjallinen kielteinen määrite)
- **EN:** that is not, un- (literary negative modifier before a noun)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(ない-vartalo) + ざる + N | 世の中には型に**あらざる**ものはない。（あらざる = ではない） |
| | 「見**ざる**、聞か**ざる**、言わ**ざる**」は一つの生き方を示している。（有名な三猿） |
| | 歴史にはまだまだ知られ**ざる**事実があるはずだ。 |
| | 世界には、許され**ざる**差別がまだ残っている。 |

## Nyanssi ja rajoitukset
- ⚠ する:n ざる-muoto on epäsäännöllinen: せざる (ei ×しざる) — sama poikkeus kuin ずに/ざるを得ない:ssä.
- Erittäin kirjallinen/vanhahtava — tunnetuin esimerkki on 三猿 (見ざる・聞かざる・言わざる, "älä näe, älä kuule, älä puhu pahaa").
- ある-verbin ざる-muoto on epäsäännöllisesti あらざる (ei ×あらない-pohjainen).

- [[～ず［に］・～ず (kirjallinen kielto)]]: ず on lauseen sisäinen kielteinen liitos/tapa; ざる on sen adnominaalinen muoto joka liittyy suoraan substantiiviin (ざる + N), kun taas ず ei voi liittyä suoraan substantiiviin.

#flashcards/grammar/n1/muodostus

Vざる＋N + verbi (ない-vartalo) :: V(ない-vartalo) + ざる + N. Esim. 知られざる事実 (tuntematon tosiasia).
Vざる＋N + する-verbi :: する → せざる (ei ×しざる). Esim. 見ざる、聞かざる、言わざる.
Vざる＋N + ある :: ある → あらざる (ei ×あらない-pohjainen). Esim. 型にあらざるもの.
