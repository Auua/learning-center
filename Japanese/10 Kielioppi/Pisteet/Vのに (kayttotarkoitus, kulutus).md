> [!abstract] Ydin
> Vのに nimeää tekemisen jota varten jokin väline/aika/raha **käytetään** — nominalisoitu tarkoitus (の) + partikkeli に. Eri asia kuin lauseen lopun konjunktio のに ("vaikka").

## Merkitys
- **FI:** [tekemistä] varten, [tekemiseen] käytetään/kuluu
- **EN:** for (the purpose of) doing ~ (used with 使う, 必要、かかる、便利)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(辞書形) + のに + 使います | このはさみは**花を切るのに**使います。 |
| | ワインを**開けるのに**使います。 |
| V(辞書形) + のに + 必要です/かかります | 結婚式を**するのに**どのくらいお金が必要ですか。 |
| | ビデオを**修理するのに**3週間もかかりました。 |
| V(辞書形) + のに + 便利です/役に立ちます | 財布や書類が別々にしまえるので、旅行や仕事に**便利なんです**。 |

## Nyanssi ja rajoitukset
- Rajoittuu tiettyihin predikaatteihin: 使う (käyttää), 必要だ (tarpeellinen), かかる (kuluu aikaa/rahaa), 便利だ/役に立つ (hyödyllinen) — ei yleiskäyttöinen kaikkiin lauseisiin.
- ⚠ Älä sekoita lauseen lopun konjunktioon のに ("vaikka, siitä huolimatta") — tämä on eri rakenne, vaikka kirjoitusasu on sama. Tässä のに tulee aina keskelle lausetta ennen edellä mainittuja predikaatteja ja nimeää käyttötarkoituksen.

## Sekaannusvaara
- ために ja のに voivat molemmat kääntyä "varten", mutta のに rajoittuu käyttötarkoitus/kulutus-konteksteihin (使う, 必要, かかる) eikä sovi yleiseen tavoitteen ilmaisuun kuten [[Vために・Nのために (tarkoitusta varten)]].
- ⚠ Sama kirjoitusasu のに on myös oma erillinen konjunktionsa: [[普通形のに (vaikka, pettymys)]] (Luku 45) tarkoittaa "vaikka" ja ilmaisee pettymystä/yllätystä — täysin eri kielioppi kuin tämä käyttötarkoitus-のに.

切るのに — käyttötarkoitus + のに + 使う.

ビデオを修理するのに3週間もかかりました。 — mikä on のに:n rooli tässä?
?
Nimeää tekemisen (ビデオの修理) jota varten aika (3週間) kului — käyttötarkoitus/kulutusrakenne, ei "vaikka"-konjunktio.
