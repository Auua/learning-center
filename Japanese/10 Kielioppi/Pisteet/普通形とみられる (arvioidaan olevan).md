> [!abstract] Ydin
> とみられる on tyypillinen **uutiskielen** ilmaus, jolla kerrotaan asiantuntijan/median arvio ilman että esitetään sitä varmana faktana — "arvioidaan olevan".

## Merkitys
- **FI:** arvioidaan olevan, katsotaan olevan
- **EN:** is thought to be, is estimated/regarded as

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + とみられる（passiivi, objektiivinen arvio） | 外部からの情報引き出しによってか、データ流失が起きたもの**とみられる**。 |
| | 犯人は車で逃げた**とみられる**。 |
| | カードの被害額は1人当たり〜**とみられている**。 |
| 普通形 + とみている（aktiivi, jonkun näkemys） | 自動車業界は東南アジアでの自動車の需要はまだまだ伸びる**とみている**。 |
| | 期待の新人はメジャーリーグに挑戦する**とみられている**。 |

## Nyanssi ja rajoitukset
- とみられる (passiivi) on yleisin uutisteksteissä, esittäen arvion ilman selvää lähdettä ("katsotaan yleisesti olevan").
- とみている (aktiivi) nimeää selkeämmin **kuka** arvioi (自動車業界は〜とみている).
- Tyypillinen rikos-/talousuutisten kieli — ei sovi arkikeskusteluun.
