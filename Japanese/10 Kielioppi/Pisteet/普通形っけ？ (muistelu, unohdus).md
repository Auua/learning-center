> [!abstract] Ydin
> っけ on puhekielinen loppupartikkeli, jolla puhuja yrittää **muistaa unohtamaansa tietoa** tai varmistaa sen kuulijalta — "miten se olikaan?".

## Merkitys
- **FI:** muistaakseni, miten se olikaan (unohdetun asian palauttaminen mieleen)
- **EN:** was it...? (trying to recall something forgotten)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形（た形） + っけ？ | 『銀河鉄道999』って、どんな話だった**っけ**? |
| | 今日は何曜日だった**っけ**? |
| | 荷物はいつ届くんだった**っけ**? |
| | ブラジルの首都ってどこだった**っけ**? |

## Nyanssi ja rajoitukset
- Käytetään lähes aina **た形:n** kanssa, vaikka kysymys koskisi nykyhetkeä tai tulevaisuutta (今日は何曜日だったっけ, ei だっけ ilman た:ta) — muistelu viittaa siihen, että tieto oli aiemmin tiedossa mutta on unohtunut.
- Erittäin puhekielinen, sopii vain rentoon/tuttavalliseen keskusteluun.
- って ennen っけ merkitsee usein aiheen nostamista (『銀河鉄道999』って) ennen muistelukysymystä.
