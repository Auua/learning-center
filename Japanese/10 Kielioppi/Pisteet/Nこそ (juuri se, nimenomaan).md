> [!abstract] Ydin
> こそ korostaa voimakkaasti, että juuri **tämä ja vain tämä** (ei mikään muu) on kyseessä — vahvin yksilöivä korostuspartikkeli.

## Merkitys
- **FI:** juuri, nimenomaan (vahva korostus, ei mikään muu)
- **EN:** it is precisely..., this is exactly what

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + こそ | **あなたこそ**、あの本の山はいったい何なの! |
| | どうぞよろしくお願いします。……**こちらこそ**どうぞよろしく。 |
| | **今年こそ**、いい人に出会えますように。 |
| V(て形) + こそ | どんな言語もコミュニケーションに**使えてこそ**意味があるのであって、〜。 |
| N + にこそ | この歌は今泣いている**あなたにこそ**聞いてほしいのです。 |

## Nyanssi ja rajoitukset
- Vahvin korostuspartikkeli — sulkee pois kaikki muut vaihtoehdot ja nostaa esiin juuri kyseisen kohteen.
- こちらこそ on erittäin yleinen kohtelias vastavuoroisuusilmaus (vastaus よろしくお願いします:iin).
- V(て形)こそ + 意味がある/価値がある on tuottava rakenne: "vasta X:n tehtyään on todella arvokasta".
