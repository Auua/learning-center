> [!abstract] Ydin
> うちに kuvaa, että jotain tapahtuu/muuttuu **tietyn tilan kestäessä**, usein huomaamatta — "sillä aikaa kun, sen tilan ollessa voimassa".

## Merkitys
- **FI:** sillä aikaa kun, sen aikana kun (usein huomaamaton muutos)
- **EN:** while, in the course of (often an unnoticed change)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形（ている） + うちに | 年月を経る**うちに**、今やアニメはなくてはならない娯楽となっている。 |
| | この時計は、使っている**うちに**、自然に動かなくなってしまった。 |
| | 10年にわたり観察している**うちに**、パンダの特徴がよく分かってきた。 |
| | 毎日練習している**うちに**、速く泳げるようになった。 |
| | 夢中で話している**うちに**、アイスクリームが溶けてしまった。 |

## Nyanssi ja rajoitukset
- Jälkilause kuvaa usein **huomaamatta tapahtunutta muutosta** — puhuja ei aktiivisesti pyrkinyt tulokseen, se vain tapahtui ajan myötä.
- Eroaa [[～ないうちに (ennen kuin)]]:sta, joka korostaa toiminnan tekemistä ennen kuin tila muuttuu (esim. 暗くならないうちに帰りましょう — "mennään kotiin ennen kuin tulee pimeä").

## Sekaannusvaara
- [[～ないうちに (ennen kuin)]]: kielteinen muoto (Vないうちに) korostaa tekemistä **ennen** muutosta; tämä myönteinen うちに kuvaa muutosta joka tapahtuu **tilan kestäessä**, usein huomaamatta.
