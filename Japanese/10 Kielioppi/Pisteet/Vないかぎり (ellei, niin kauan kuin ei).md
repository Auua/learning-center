> [!abstract] Ydin
> ないかぎり ilmaisee, että jälkimmäinen tila pysyy voimassa **niin kauan kuin** mainittua muutosta/tekoa ei tapahdu — "ellei X tapahdu, Y pysyy samana". Rajaa tilan kestoa kielteisen ehdon avulla.

## Merkitys
- **FI:** ellei, niin kauan kuin ei
- **EN:** unless, as long as ~ not

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(ない形) + かぎり | 面倒くさいきずなを、ズタズタに切りさか**ぬかぎり**、型にはまらないで暮らすわけにはゆきません。 |
| | 私が病気にでもなら**ぬかぎり**、この店は売りません。 |
| | あきらめ**ないかぎり**、チャンスは必ず来ると思う。 |
| | ご本人の了承が**ないかぎり**、個人情報はご提供できません。 |

## Nyanssi ja rajoitukset
- ぬ on klassinen kieltomuoto (kirjallisempi vaihtoehto ない:lle) — molemmat esiintyvät tässä rakenteessa.
- Korostaa **pysyvää tilaa** joka jatkuu niin kauan kuin ehto ei täyty — ei kertaluontoista tapahtumaa.
