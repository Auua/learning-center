> [!abstract] Ydin
> N という N = **"jokainen N, kaikki N:t poikkeuksetta"** — sama substantiivi toistuu: 窓という窓.

## Merkitys
- **FI:** jokainen, kaikki poikkeuksetta
- **EN:** every single, all (without exception)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + という + N | 窓**という**窓が割れた。 |
| N という N + が | 店**という**店**が**閉まっていた。 |

## Nyanssi ja rajoitukset
- Sama substantiivi toistuu; korostaa poikkeuksettomuutta.
- Kirjallinen kuvaus, usein dramaattinen.
- Eri kuin nimeävä という (〜という名前).
