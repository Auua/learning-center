> [!abstract] Ydin
> Kaksi läheistä rakennetta nimeämiseen: 〜を〜と言う määrittelee mitä jokin **kutsutaan** (yleinen termi); 〜という〜 esittelee **tuntemattoman erisnimen** ("niminen").

## Merkitys
- **NをNと言う (FI):** N1:tä kutsutaan N2:ksi
- **Nという〜 (FI):** N-niminen ~, jota kutsutaan N:ksi

## Muodostus
| Kaava | Käyttö | Esimerkki |
|---|---|---|
| N1 + を + N2 + と言います | määritellä yleinen termi | 正月に食べる料理を**何と言いますか**。……おせち料理**と言います**。 |
| | | 畳の部屋**を**和室**と言います**。 |
| N（tuntematon）+ という + N（yleiskäsite） | esitellä erisnimi | 村上春樹**という**作家を知っていますか。 |
| | | トンガ王国**という**国です。 |
| N（tuntematon）+ という + 方/人（kohtelias） | esitellä henkilö kohteliaasti | 岡田さん**という**方から電話がありました。 |

## Nyanssi ja rajoitukset
- 〜を〜と言う vastaa kysymykseen "mitä tämä on nimeltään/miksi tätä kutsutaan" — sopii kun molemmat termit (konkreettinen asia ja sen nimi) ovat jo osa keskustelua.
- という esittelee nimen joka on **kuulijalle todennäköisesti tuntematon** — toimii siltana erisnimen ja sen yleiskäsitteen välillä ("X-niminen kirjailija", "Y-niminen maa").
- 何と言いますか on yleinen kysymys kun ei tiedä sanaa jollekin: これは日本語で何と言いますか。

## Sekaannusvaara
- Ei sekoiteta [[普通形と言います (lainaus)]]:iin — と言います lainaa jonkun puhetta/mielipidettä (ミラーさんは出張すると言いました), tämä muistiinpano nimeää käsitteitä/asioita (料理を何と言いますか).
- Ei sekoiteta [[普通形という～ (raportoitu sisalto)]]:iin (Luku 2): tässä muistiinpanossa という esittelee **erisnimen** (村上春樹という作家); Luvun 2 という kuvailee **kokonaisen lauseen sisällön** ennen substantiivia (会社を辞めたといううわさ).
- Ks. myös [[～というのは～のことだ・ということだ (maaritelma)]] (Luku 2): käänteinen näkökulma — siellä lähdetään termistä kohti selitystä, tässä lähdetään asiasta kohti nimeä.

何と言います — kysyy nimeä/termiä jollekin konkreettiselle asialle.

村上春樹という作家を知っていますか。 — mikä という:n tehtävä tässä on?
?
Esittelee kuulijalle mahdollisesti tuntemattoman erisnimen (村上春樹) siltana yleiskäsitteeseen (作家).
