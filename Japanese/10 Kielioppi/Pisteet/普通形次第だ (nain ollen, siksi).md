> [!abstract] Ydin
> 次第だ päättää muodollisen kirjeen/puheen selittämällä **miten/miksi tähän tilanteeseen päädyttiin** — "näin ollen, tästä syystä". Hyvin muodollinen, tyypillinen liikekirjeissä.

## Merkitys
- **FI:** näin ollen, tästä syystä (muodollinen selitys tapahtumaketjulle)
- **EN:** that is the reason why, this is how it came to be (formal)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形（た形） + 次第です | ネクロロジー集に玉稿をたまわりたく、お手紙をさしあげた**次第です**。 |
| | 関係者が情報を共有すべきだと考え、皆様にお知らせした**次第です**。 |
| | 私どもだけではどうしようもなく、こうしてお願いに参った**次第でございます**。 |
| | ご連絡を差し上げた**次第です**。 |

## Nyanssi ja rajoitukset
- Erittäin muodollinen — käytetään liikekirjeissä ja puheissa selittämään kohteliaasti koko tapahtumaketjun taustan ennen pyyntöä tai ilmoitusta.
- でございます on です:n vielä kohteliaampi muoto, tyypillinen kirjallisessa liike-etiketissä.
