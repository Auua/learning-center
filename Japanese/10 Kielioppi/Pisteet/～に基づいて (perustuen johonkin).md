> [!abstract] Ydin
> に基づいて merkitsee konkreettisen **perustan/lähtökohdan**, johon toiminta tai päätös nojaa — usein data, tosiasiat tai kokemus.

## Merkitys
- **FI:** perustuen johonkin, jonkin pohjalta
- **EN:** based on

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + に基づいて + V | 日本の食事スタイルの問題点を、データ**に基づいて**お話ししたいと思います。 |
| | この映画は、事実**に基づいて**作られている。 |
| N + に基づいた + N2 | デパートでは、調査結果**に基づいた**新しいサービスを導入した。 |
| | 予想ではなく、経験**に基づいて**判断しました。 |

## Nyanssi ja rajoitukset
- Vaatii konkreettisen perustan (データ, 事実, 経験, 調査結果, 意見) — muodollinen, tyypillinen esityksissä ja raporteissa.
- に基づいた + N toimii adnominaalisena määritteenä.
