> [!abstract] Ydin
> と merkitsee lainausta: **「X」と読みます** = luetaan "X"; **「X」と書きます** = kirjoitetaan "X". Kysymys: 何と読みますか (miten luetaan?).

## Merkitys
- **FI:** luetaan (näin) / kirjoitetaan (näin)
- **EN:** is read as / is written as

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N は 何と読みますか | あの漢字は**何と読みます**か。 |
| N は「X」と読みます | 「止」は「とまれ」**と読みます**。 |
| N は どう書きますか／何と書きますか | 「さくら」は漢字で**どう書きます**か。 |

## Nyanssi ja rajoitukset
- Lainausmerkki と — sama kuin 「S」と言います (Luku 21).
- Puhekielessä usein んです-muodossa: 何と読む**んですか**.
- どう書きますか (miten kirjoitetaan, tapa) ja 何と書きますか (mitä kirjoitetaan) ovat lähes vaihtokelpoisia.
