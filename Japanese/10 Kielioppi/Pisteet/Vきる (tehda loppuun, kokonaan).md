> [!abstract] Ydin
> きる liitettynä ます-vartaloon korostaa, että teko/tila on saavuttanut **täydellisen, äärimmäisen asteen** — "täysin, kokonaan, loppuun asti".

## Merkitys
- **FI:** täysin, kokonaan, loppuun asti
- **EN:** completely, entirely, to the fullest extent

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(ます-vartalo) + きった | その竹の一片に彼の肉体と精神を**まかせきった**。 |
| | 赤ちゃんは**安心しきった**表情で母親の胸で眠っている。 |
| | 山本さんは**疲れきった**顔で座り込んでいる。 |
| V(ます-vartalo) + っきり（puhekielinen） | 子育てを母親に**まかせっきり**にしている父親が多い。 |

## Nyanssi ja rajoitukset
- Korostaa tilan/teon **äärimmäistä täydellisyyttä** — ei vain "melko" vaan "täysin, loppuun asti".
- っきり on puhekielinen supistuma きり:stä, usein negatiivisen sävyn kanssa (まかせっきり = "jättää kokonaan jonkun muun hoidettavaksi", moittiva).

#flashcards/grammar/n2/muodostus

V(ます-vartalo)＋きる + verbi :: V(ます-vartalo) + きる/きった. Esim. 疲れきった顔で座り込んでいる。
V(ます-vartalo)＋っきり + verbi (puhekielinen) :: V(ます-vartalo) + っきり. Esim. 子育てを母親にまかせっきりにしている父親が多い。
