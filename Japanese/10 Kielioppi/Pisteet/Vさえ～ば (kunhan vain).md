> [!abstract] Ydin
> さえ〜ば eristää **yhden riittävän ehdon** kaiken muun joukosta — "kunhan vain tämä yksi asia toteutuu, kaikki muu seuraa/riittää". Korostaa ehdon minimaalisuutta ja riittävyyttä.

## Merkitys
- **FI:** kunhan vain, jos vain (riittävä minimiehto)
- **EN:** as long as, if only (a single sufficient condition)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(ます-vartalo) + さえすれば | なんでも型にはめ**さえすれば**、間違いは、おこり得ないのです。 |
| | 非常用として3日分の水と食料を蓄えておき**さえすれば**、あとは何とかなる。 |
| | このグラウンドは、市役所に申し込み**さえすれば**、誰でも使えます。 |
| V(て形) + さえいれば | 家族が健康に暮らして**さえいれば**、十分に幸せです。 |

## Nyanssi ja rajoitukset
- Korostaa, että mainittu ehto on **ainoa tarvittava** — kaikki muu on toissijaista tai seuraa automaattisesti.
- Rakenteellisesti さえ lisätään ます-vartaloon tai て形:ään ennen ば/すれば/いれば.
