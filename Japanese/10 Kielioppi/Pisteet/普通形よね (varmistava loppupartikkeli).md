> [!abstract] Ydin
> よね yhdistää よ:n (uuden tiedon painotus) ja ね:n (samanmielisyyden hakeminen) — puhuja on melko varma asiasta mutta hakee silti kuulijan vahvistusta: "eikö totta?".

## Merkitys
- **FI:** eikö niin, eikö totta (varmistava, melko varma puhuja)
- **EN:** right?, isn't it? (seeking confirmation while fairly confident)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + よね | 「辛党」は「甘党」の反対だと思ってた**のよね**。 |
| | 冬の寒い朝ってなかなかベッドから出られない**よね**。……うん。 |
| | パーティは楽しいけど、帰るときが寂しいんです**よね**。……そうですよね。 |
| | ポテトチップスって食べ始めると、なかなかやめられないんだ**よね**。……本当に。 |

## Nyanssi ja rajoitukset
- Ero pelkkään ね:hen: よね sopii kun puhuja on **melko varma** väitteestään mutta silti pehmentää sitä hakemalla vahvistusta (esittää yhteisen kokemuksen/mielipiteen todennäköisenä totuutena).
- Ero pelkkään よ:hun: よね on pehmeämpi, ei tyrkytä tietoa yhtä suoraan vaan kutsuu kuulijan mukaan keskusteluun.
- Erittäin yleinen arkikeskustelussa small talkin ylläpitämisessä ja yhteisymmärryksen rakentamisessa.
