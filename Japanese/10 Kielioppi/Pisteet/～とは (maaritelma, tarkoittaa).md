> [!abstract] Ydin
> とは merkitsee sanan/käsitteen jota ollaan määrittelemässä tai jonka merkityksestä puhutaan — と (lainaus) + は (topiikki) supistuma, hieman muodollisempi ja tiiviimpi kuin というのは.

## Merkitys
- **FI:** tarkoittaa sitä että..., mikä (X) on
- **EN:** ~ means, as for the definition of ~

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + とは、普通形 + ことだ | 海外で日本のテレビアニメが受けるわけ**とは**何だろうか。 |
| | 「負けるが勝ち」**とは**、相手を勝たせるほうが結局は自分が得をすることがあるということだ。 |
| | 彼女にとって家族**とは**いったい何か。 |
| | 外食**とは**、レストランなどで食事をすることだ。 |
| | 夕刊**とは**、夕方に発行する新聞のことだ。 |

## Nyanssi ja rajoitukset
- Sopii sekä kirjoitettuun määritelmätekstiin (夕刊とは〜のことだ) että retoriseen kysymykseen (家族とはいったい何か) jossa käsitteen merkitystä pohditaan.
- Tiiviimpi ja hieman muodollisempi kuin [[～というのは～のことだ・ということだ (maaritelma)]] — molemmat toimivat samassa määrittely-funktiossa.

## Sekaannusvaara
- [[～というのは～のことだ・ということだ (maaritelma)]]: sama funktio (määritelmä), mutta pidempi ja puhekielisempi muoto; とは on sen tiivistetty, hieman kirjallisempi vastine.
