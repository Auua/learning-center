> [!abstract] Ydin
> N + なりに = **"(rajoitukset huomioiden) omalla tavallaan"** — tehdään parhaansa omien edellytysten mukaan.

## Merkitys
- **FI:** omalla tavallaan, omien edellytystensä mukaan
- **EN:** in one's own way, as best one can (given limits)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + なりに | 子ども**なりに**考えている。 |
| N + なりの + N | 私**なりの**意見 |
| 普通形 + なりに | 狭い**なりに**、使いやすい部屋だ。 |

## Nyanssi ja rajoitukset
- N on usein puhuja tai ryhmä, jolla on rajoituksia: 子ども, 素人, 私.
- Myönteinen tunnustus: vaikka rajallinen, yrittää parhaansa.
- それなりに = omalla tavallaan, kohtuullisesti.
