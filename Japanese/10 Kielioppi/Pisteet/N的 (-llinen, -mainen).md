> [!abstract] Ydin
> Sino-japanilainen substantiivi + 的 tekee siitä **な-adjektiivin**: 経済 → 経済的 (taloudellinen), 積極 → 積極的 (aktiivinen).

## Merkitys
- **FI:** -llinen, -mainen, -inen (johdin)
- **EN:** -ic, -al, -ive

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + 的な + N | 経済**的な**問題 |
| N + 的に + V/Adj | 積極**的に**参加する。 |
| N + 的だ | その考えは現実**的だ**。 |

## Nyanssi ja rajoitukset
- Liittyy yleensä kanji-substantiiveihin (漢語): 科学的, 国際的, 個人的, 具体的, 一般的.
- Taipuu な-adjektiivina: 的な + N, 的に + verbi.
- Muodollinen ja kirjoitettu; uutiset, raportit, esseet.
