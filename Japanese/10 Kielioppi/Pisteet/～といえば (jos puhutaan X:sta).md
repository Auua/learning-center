> [!abstract] Ydin
> といえば nostaa esiin aiheen ja liittää siihen välittömän assosiaation/esimerkin — "jos puhutaan X:stä, niin ensimmäisenä tulee mieleen Y". Käytetään erityisesti keskustelun aiheen vaihtamiseen luontevasti.

## Merkitys
- **FI:** jos puhutaan X:stä, X:stä tulee mieleen
- **EN:** speaking of X, when it comes to X

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + といえば | 太鼓**といえば**、佐渡の「鬼太鼓」が有名ですよね。 |
| | 温泉**といえば**、まず城崎温泉を思い浮かべますね。 |
| N + というと | 教育**というと**、学校の仕事だと思うかもしれないが、そうではない。 |
| N + といったら | 日本**といったら**、若い人はアニメ、中年以上の人は車と言うだろう。 |
| aiheen vaihto keskustelussa | 落とし物**といえば**、この間、高速道路を馬が走り回ったそうですよ。 |

## Nyanssi ja rajoitukset
- Erittäin hyödyllinen keskustelun ylläpitämiseen: kuulija voi ottaa toisen mainitseman sanan ja siirtyä siitä uuteen, assosioituun aiheeseen (落とし物の話 → 落とし物といえば、別の落とし物の話).
- といえば, というと, といったら ovat lähes vaihtokelpoisia, sävyerot pieniä (といったら hieman puhekielisempi/tunnepitoisempi).
