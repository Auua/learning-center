> [!abstract] Ydin
> の末（に） kertoo, että jokin lopputulos saavutettiin **pitkän, usein vaivalloisen prosessin jälkeen** — korostaa matkan pituutta/vaivaa ennen lopputulosta.

## Merkitys
- **FI:** pitkän X:n jälkeen, lopulta (vaivalloisen prosessin päätteeksi)
- **EN:** after a long period of, in the end (after much effort)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N（kesto） + の末（に） | クリストファーさんは30年**にわたる**経験**の末**、こう語る。 |
| | 5年間の受験勉強**の末**、ようやく国家試験に合格できた。 |
| | 長時間にわたる議論**の末**、全員の意見が一致した。 |
| V(た形) + 末（に） | 苦労した**末**、画家はやっと作品を完成させることができた。 |
| | いろいろな仕事をわたり歩いた**末に**、結局最初の仕事に落ち着いた。 |

## Nyanssi ja rajoitukset
- Korostaa erityisesti **prosessin pituutta/vaivaa** ennen lopputulosta — ei sovi hetkellisiin tai vaivattomiin tapahtumiin.
- Usein yhdistetään sanoihin とうとう, やっと, ようやく korostamaan pitkän odotuksen päättymistä.
