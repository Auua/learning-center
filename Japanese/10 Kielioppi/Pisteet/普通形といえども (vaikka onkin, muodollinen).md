> [!abstract] Ydin
> といえども on erittäin muodollinen/kirjallinen myönnytysilmaus — "vaikka onkin X" — tyypillinen kirjoitetussa, hieman vanhahtavassa tai retorisessa tekstissä.

## Merkitys
- **FI:** vaikka onkin, olipa X kuinka tahansa (muodollinen)
- **EN:** even though, however much (formal/literary)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + といえども | 水をそのまま生で飲める国など世界広し**といえども**そう多くはない。 |
| | どんな大金持ち**といえども**、お金で解決できない悩みがあるはずだ。 |
| | 名医**といえども**、すべての患者を救うことはできない。 |
| | 広い日本**といえども**、旅行したいところはたくさんある。 |

## Nyanssi ja rajoitukset
- Erittäin kirjallinen/muodollinen — kuulostaisi vanhahtavalta arkikeskustelussa; tyypillinen esseissä, puheissa, kirjallisessa retoriikassa.
- Usein liittyy laajaan yleistykseen jota sitten rajoitetaan ("vaikka X onkin laaja/mahtava kategoria, silti...").
