> [!abstract] Ydin
> てはじめて korostaa, että jokin oivallus/ymmärrys syntyi **vasta** kyseisen kokemuksen myötä — ei ennen sitä. Usein käytetään kertomaan, kuinka jokin asia tuli todella ymmärretyksi vasta oman kokemuksen kautta.

## Merkitys
- **FI:** vasta ~ tehtyään/koettuaan (ymmärsi), ei ennen sitä
- **EN:** only after ~ing did (one realize)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(て形) + はじめて、+ oivallus | 優太が幼稚園に行くようになって**はじめて**節分のことを知りました。 |
| | 子どもを持って**はじめて**親のありがたさがわかった。 |
| | 就職して**はじめて**お金を稼ぐことの大変さを知りました。 |
| | 病気になって**はじめて**健康の大切さが分かった。 |

## Nyanssi ja rajoitukset
- Jälkilause on lähes aina **ymmärrys/oivallus** (わかった, 知った, 気づいた) — ei mikä tahansa teko.
- Korostaa implisiittisesti, ettei ymmärrystä ollut **ennen** kyseistä kokemusta — usein käytetään kertomaan elämänkokemuksen tuomasta viisaudesta.
