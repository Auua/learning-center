> [!abstract] Ydin
> をはじめ nostaa esiin **kaikkein edustavimman/tärkeimmän esimerkin** ryhmästä ja jatkaa listaamaan muita — "N:stä alkaen, N mukaan lukien ensimmäisenä".

## Merkitys
- **FI:** mukaan lukien (esimerkiksi ensimmäisenä), N:stä alkaen
- **EN:** starting with N, N and others (N as the prime example)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + をはじめ、N2など | 白神山地にはクマゲラ**をはじめ**、多種多様な動植物が見られます。 |
| | カラオケ**をはじめ**、ジュードー、ニンジャなど、世界共通語になった日本語は数多くある。 |
| | ナスカの地上絵**をはじめ**、ネッシー、バミューダ・トライアングルなどいまだ多くの謎が存在する。 |
| N（henkilö）+ をはじめ | 市長**をはじめ**、皆様のご協力で今日のこの日を迎えることができました。 |

## Nyanssi ja rajoitukset
- Toisin kuin [[～といった (esimerkiksi tallainen kuin)]], joka listaa tasavertaisia esimerkkejä, をはじめ nostaa **yhden ensisijaisen/edustavimman** esimerkin ennen muita.
- Henkilöluettelossa (市長をはじめ) osoittaa kunnioitusta nimeämällä arvokkain henkilö ensin.

## Sekaannusvaara
- [[～といった (esimerkiksi tallainen kuin)]]: listaa tasavertaisia esimerkkejä ilman hierarkiaa; をはじめ korostaa yhtä **ensisijaista/edustavinta** esimerkkiä muiden joukossa.
