> [!abstract] Ydin
> ぞ on voimakas, karkeahko loppupartikkeli joka korostaa uutta tietoa tai varoitusta — pääasiassa miesten käyttämä, tuttavallinen/epämuodollinen rekisteri.

## Merkitys
- **FI:** kuulehan (vahva, tuttavallinen korostus, usein varoitus/huomio)
- **EN:** hey, listen (strong, blunt emphasis — mainly male speech)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| S + ぞ | すごい音楽がある**ぞ**。 |
| | 気をつけろ。このあたりは毒へビがいる**ぞ**。 |
| | おーい。ここにあった**ぞ**。 |
| | この本、おもしろい**ぞ**。読んでみろ。 |

## Nyanssi ja rajoitukset
- Selvästi karkeampi/tuttavallisempi kuin [[Sよ (uuden tiedon korostus)]] — käytetään perinteisesti enemmän miesten puheessa, läheisten kesken tai itsekseen puhuttaessa.
- Usein liittyy varoitukseen, huomion herättämiseen tai innostuneeseen huudahdukseen.
- Ei sovi kohteliaaseen tai muodolliseen puheeseen.
