> [!abstract] Ydin
> 結果 esittää jälkilauseen **lopputuloksena/seurauksena** edeltävästä prosessista tai toimenpiteestä — usein käytetään tutkimusten, neuvottelujen tai päätöksentekoprosessien yhteydessä.

## Merkitys
- **FI:** seurauksena, lopputuloksena
- **EN:** as a result of

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(た形) + 結果、… | 妻と**相談した結果**、わたしたちは両親といっしょに住むことにした。 |
| | 国際会議で**話し合った結果**、CO2を減らす努力をすることになった。 |
| N + の + 結果、… | **抽選の結果**、お客様が一等に選ばれましたので、お知らせいたします。 |
| N + の + 結果、〜ことがわかった | **調査の結果**、沖縄県の女性がいちばん長生きすることがわかりました。 |

## Nyanssi ja rajoitukset
- Etulauseen on aina oltava **prosessi tai toimenpide** joka johti lopputulokseen (相談する, 話し合う, 調査する, 交渉する) — ei sovi pelkkään syy-seuraus-suhteeseen ilman prosessin vaihetta.
- Yleinen tutkimustulosten ja virallisten ilmoitusten kaava: 調査/アンケート/投票 + の結果.
- Muodollisempi ja tarkempi kuin から/ので — ilmaisee nimenomaan lopputuloksen prosessin päätteeksi.
