> [!abstract] Ydin
> N + に慣れる = **"tottua N:ään"**; tila: 慣れている = on tottunut.

## Merkitys
- **FI:** tottua johonkin
- **EN:** get used to, become accustomed to

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + に慣れる | 日本の生活**に慣れました**。 |
| V辞書形 + の + に慣れる | 早く起きる**のに慣れた**。 |
| N + に慣れている（tila） | 彼は人前で話すこと**に慣れている**。 |

## Nyanssi ja rajoitukset
- Kohde merkitään に:llä, ei を:lla: ×生活を慣れる.
- Verbin kanssa nominalisoidaan: 〜のに / 〜ことに慣れる.
- 慣れている = on tottunut (tila); 慣れた = tottui (muutos tapahtui).
