> [!abstract] Ydin
> N + だらけ = **"täynnä / kauttaaltaan N:ää"** — lähes aina jotain ikävää (likaa, virheitä).

## Merkitys
- **FI:** täynnä, yltä päältä, -n peitossa (kielteinen)
- **EN:** full of, covered with (negative)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + だらけ | 部屋がごみ**だらけ**だ。 |
| N + だらけの + N | 間違い**だらけの**作文 |
| N + だらけになる | 子どもが泥**だらけになって**帰ってきた。 |

## Nyanssi ja rajoitukset
- Lähes aina kielteinen: ごみ, 泥, 血, 傷, 間違い, 借金.
- Ei positiivisista: ×花だらけ (paitsi ironisesti) → 花でいっぱい.
- Taipuu kuten substantiivi: だらけだ, だらけの, だらけになる.
