> [!abstract] Ydin
> Myönteisessä lauseessa ほど ilmaisee **asteen/määrän konkreettisen esimerkin kautta** — kuvataan kuinka voimakas jokin on vertaamalla sitä johonkin elävään, usein liioittelevaan seuraukseen ("niin X että Y").

## Merkitys
- **FI:** niin paljon/voimakkaasti että, siinä määrin että
- **EN:** to the extent that, so much that

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + ほど + adj/V | のみこむのに苦労した日本語は、佃煮にする**ほど**あった。 |
| 普通形 + ほど + adj | このカレーは涙が出る**ほど**辛い。 |
| | 昨夜はシャワーを浴びずに寝てしまう**ほど**疲れていた。 |
| | 今年は捨てる**ほど**ミカンがとれた。 |
| | この掃除機は使っていても誰も気づかない**ほど**静かだ。 |

## Nyanssi ja rajoitukset
- Toisin kuin [[～ほど～ない・ほどではない (vertailu, ei niin)]], tämä käyttö on **myönteinen** — ei vertaa kahta asiaa keskenään, vaan kuvaa yhden asian astetta elävän/konkreettisen seurauksen kautta.
- Vertailukohtana käytetään usein liioiteltua/dramaattista esimerkkiä (涙が出るほど辛い, 誰も気づかないほど静かだ) tehostamaan kuvausta.
- Eroaa myös [[～ほど～はない・いない (superlatiivi)]]:sta, joka vertaa henkilöä/asiaa muihin samankaltaisiin (superlatiivi), ja [[Vば〜ほど (mita enemman, sita)]]:sta, joka kuvaa kahden muuttujan yhtäaikaista kasvua.

## Sekaannusvaara
- Neljä eri ほど-rakennetta samassa vaultissa: (1) tämä = aste/esimerkki (myönteinen), (2) [[～ほど～ない・ほどではない (vertailu, ei niin)]] = vertailu (kielteinen), (3) [[～ほど～はない・いない (superlatiivi)]] = superlatiivi, (4) [[Vば〜ほど (mita enemman, sita)]] = kahden muuttujan yhtäaikainen kasvu.
