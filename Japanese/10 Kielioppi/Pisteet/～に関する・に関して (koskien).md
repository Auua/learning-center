> [!abstract] Ydin
> に関する／に関して on について:n muodollinen vastine — ilmaisee aiheen josta puhutaan/kirjoitetaan/tutkitaan.

## Merkitys
- **FI:** koskien, liittyen (muodollinen)
- **EN:** regarding, concerning (formal)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + に関する + N2 | 働きアリ**に関する**有名な研究がある。 |
| | 東京で環境問題**に関する**会議が開かれた。 |
| N + に関して | 今回の講演会**に関して**ご意見のある方はこの紙に書いてください。 |
| | このレポートでは、日本経済の現状**に関して**説明する。 |

## Nyanssi ja rajoitukset
- に関する liittää suoraan seuraavaan substantiiviin (に関する＋N2, kuten "koskeva N2"); に関して toimii adverbiaalina lauseen keskellä (について:n tapaan).
- Muodollisempi kuin について — sopii tutkimuksiin, raportteihin, virallisiin ilmoituksiin.
