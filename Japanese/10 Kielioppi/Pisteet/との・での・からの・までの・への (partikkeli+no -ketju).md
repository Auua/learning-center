> [!abstract] Ydin
> Partikkeli + の muuttaa partikkelilausekkeen substantiivin määreeksi — tiivistää relatiivilauseen yhdeksi kompaktiksi ilmaukseksi (esim. "ystävältä saatu sähköposti" → "ystävältä-の sähköposti").

## Merkitys
- **との (FI):** ...:n kanssa oleva
- **での (FI):** ...:ssa tapahtuva/oleva
- **からの (FI):** ...:sta tuleva
- **までの (FI):** ...:hin asti oleva
- **への (FI):** ...:lle suuntautuva

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + との + N | あしたは友達**との**約束があって、行けません。 |
| N + での + N | 日本**での**生活にもう慣れましたか。 |
| N + からの + N | 母**からの**手紙は箱の中に大切にしまってあります。 |
| N + までの + N | 羽田は空港**までの**アクセスがよくて、人気があります。 |
| N + への + N | これは恋人**への**プレゼントです。 |

## Nyanssi ja rajoitukset
- Tiivistää lauseen: 友達からもらったメール → 友達**からの**メール (ystävältä saatu → ystävältä tuleva). Molemmat ovat oikein, mutta partikkeli+の on kompaktimpi ja kirjallisempi.
- Kaikki tavalliset paikka/suunta-partikkelit (と, で, から, まで, へ) voivat saada の:n tässä tehtävässä — muista ettei に yleensä käytetä tällä tavalla samalla tuottavuudella.
- Erityisen yleinen otsikoissa, kutsuissa ja muodollisissa ilmoituksissa: 東京への出張, 先生からのメッセージ.

## Kortit
#flashcards/grammar/n3

母＿＿＿手紙は箱の中に大切にしまってあります。(から, lahde)
?
からの — partikkeli(から) + の, substantiivin määre.

Mitä eroa on 友達からもらったメール:llä ja 友達からのメール:llä?
?
Molemmat tarkoittavat samaa; jälkimmäinen (partikkeli+の) on kompaktimpi ja kirjallisempi tapa ilmaista sama asia ilman erillistä relatiivilausetta.

#flashcards/grammar/n3/muodostus

N との N / N での N :: N + との + N = 'kanssa oleva' (友達との約束); N + での + N = 'ssa tapahtuva' (日本での生活)
N からの N / N までの N :: N + からの + N = 'sta tuleva' (母からの手紙); N + までの + N = 'hin asti oleva' (空港までのアクセス)
N への N :: N + への + N = 'lle suuntautuva'. Esim. これは恋人へのプレゼントです。 (lahja rakkaalle)

#flashcards/grammar/n3/nyanssi

Mitä hyötyä partikkeli+の -ketjusta on verrattuna relatiivilauseeseen (友達からもらったメール)?
?
Tiivistää lauseen: 友達からのメール on kompaktimpi ja kirjallisempi kuin 友達からもらったメール.

Mitkä partikkelit voivat saada の:n ketjussa partikkeli+の, ja mikä on に:n asema?
?
と, で, から, まで, へ; に:aa ei yleensä käytetä tällä tavalla samalla tuottavuudella.

Missä yhteyksissä partikkeli+の on erityisen yleinen?
?
Otsikoissa, kutsuissa ja muodollisissa ilmoituksissa: 東京への出張, 先生からのメッセージ.
