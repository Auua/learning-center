> [!abstract] Ydin
> Partikkeli + の muuttaa partikkelilausekkeen substantiivin määreeksi — tiivistää relatiivilauseen yhdeksi kompaktiksi ilmaukseksi (esim. "ystävältä saatu sähköposti" → "ystävältä-の sähköposti").

## Merkitys
- **との (FI):** ...:n kanssa oleva
- **での (FI):** ...:ssa tapahtuva/oleva
- **からの (FI):** ...:sta tuleva
- **までの (FI):** ...:hin asti oleva
- **への (FI):** ...:lle suuntautuva

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + との + N | あしたは友達**との**約束があって、行けません。 |
| N + での + N | 日本**での**生活にもう慣れましたか。 |
| N + からの + N | 母**からの**手紙は箱の中に大切にしまってあります。 |
| N + までの + N | 羽田は空港**までの**アクセスがよくて、人気があります。 |
| N + への + N | これは恋人**への**プレゼントです。 |

## Nyanssi ja rajoitukset
- Tiivistää lauseen: 友達からもらったメール → 友達**からの**メール (ystävältä saatu → ystävältä tuleva). Molemmat ovat oikein, mutta partikkeli+の on kompaktimpi ja kirjallisempi.
- Kaikki tavalliset paikka/suunta-partikkelit (と, で, から, まで, へ) voivat saada の:n tässä tehtävässä — muista ettei に yleensä käytetä tällä tavalla samalla tuottavuudella.
- Erityisen yleinen otsikoissa, kutsuissa ja muodollisissa ilmoituksissa: 東京への出張, 先生からのメッセージ.
