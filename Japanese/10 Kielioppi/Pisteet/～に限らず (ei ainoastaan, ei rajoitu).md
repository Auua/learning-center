> [!abstract] Ydin
> に限らず laajentaa väitteen koskemaan muitakin kuin mainittua tapausta — "ei rajoitu vain X:ään, vaan koskee laajemminkin". Rakenteellisesti 限る:n (rajoittua) kielteinen muoto.

## Merkitys
- **FI:** ei ainoastaan, ei rajoitu vain jompaankumpaan
- **EN:** not limited to, not only

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + に限らず、N2でも | このような現象は日本**に限らず**、ブラジルでも他の国でも起きている。 |
| | このキャラクターは、子ども**に限らず**大人にも人気がある。 |
| | お寿司やてんぷら**に限らず**、豆腐料理なども人気がある。 |
| | 障害を持った人やお年寄り**に限らず**、だれでもが快適に利用できる。 |

## Nyanssi ja rajoitukset
- Toiminnallisesti lähellä [[～だけでなく (ei pelkastaan vaan myos)]]:tä, mutta に限らず korostaa erityisesti, ettei asia ole **rajoittunut** yhteen tapaukseen — sopii erityisesti kun halutaan kumota oletettu rajoitus.
- 限る (rajoittua) on juurisana — vrt. [[N・普通形に限って (juuri silloin, ikava sattuma)]], joka käyttää samaa verbiä eri, myönteisessä muodossa täysin eri merkitykseen.

## Sekaannusvaara
- [[N・普通形に限って (juuri silloin, ikava sattuma)]]: käyttää samaa 限る-verbiä mutta täysin eri merkityksessä (korostaa juuri kyseistä tapausta, ei laajenna sitä) — älä sekoita näitä kahta pintapuolisesti samankaltaista rakennetta.
