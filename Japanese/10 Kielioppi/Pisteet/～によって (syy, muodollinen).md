> [!abstract] Ydin
> によって:llä on kolmas, erillinen käyttö: muodollinen **syyn** merkitseminen ("jonkin vuoksi/johdosta") — ei tekijää eikä vaihtelun perustetta, vaan suora syy-seuraussuhde.

## Merkitys
- **FI:** jonkin vuoksi, jonkin johdosta (muodollinen syy)
- **EN:** due to, as a result of (formal cause)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N（syy） + によって | 外部からの情報引き出し**によって**、データ流失が起きたものとみられる。 |
| | 急激な円高**によって**経営が苦しくなり、倒産する企業もある。 |
| | ATMのトラブル**による**被害は、この銀行の利用者にとどまらない。 |
| | 少子高齢化**によって**、地域社会はますます活力がなくなっている。 |

## Nyanssi ja rajoitukset
- Muodollinen, uutis-/raporttityylinen syy-ilmaus — sopii tilastoihin, uutisiin, virallisiin selvityksiin.
- による + N toimii adnominaalisena määritteenä (による被害 = "aiheutunut vahinko").

## Laajennus: keino/menetelmä (により on kirjallinen vastine)
Sama によって kattaa myös **keinon/menetelmän**, jolla jokin tulos saavutetaan — läheistä sukua syy-käytölle, usein myönteisessä kontekstissa:
- 宅配便**によって**、全国どこへでも遅くとも2日以内には荷物が届くようになった。
- 生活習慣病は、生活習慣の改善**によって**治すことができる。
- 改暦を行うこと**により**、12月の給料を1か月分払わずに済ませた。（により on によって:n kirjallisempi vastine）
- 工場を海外に移したこと**により**、コストを下げるのに成功した。

## Sekaannusvaara
- Kolme erillistä によって-kielioppia samassa vaultissa: (1) [[〜によって (tekijan merkitseminen, luova teko)]] = passiivin tekijä luovassa teossa (ライト兄弟によって発明された); (2) [[～によって (riippuen, vaihtelu)]] = vaihtelun peruste (文化は国によって違う); (3) tämä = suora muodollinen syy (円高によって経営が苦しくなった). Erottelu vaatii kontekstin: onko lause passiivi luovasta teosta, vaihteleeko jokin N:n mukaan, vai kuvataanko suoraa syy-seurausta.
