> [!abstract] Ydin
> はともかく jättää mainitun asian **käsittelemättä/sivuun** ("jätetään X sikseen") ja siirtää huomion johonkin toiseen, usein tärkeämpänä pidettyyn asiaan.

## Merkitys
- **FI:** jätetään X sikseen, X:stä riippumatta, joka tapauksessa
- **EN:** leaving X aside, regardless of X

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + はともかく、+ toinen näkökulma | 彼らのふるまいの変化**はともかく**、彼らの顔が以前に比べて、おだやかになる。 |
| | あのレストランは値段**はともかく**、味はいい。 |
| | 彼は見た目**はともかく**、性格がいい。 |
| 普通形か + はともかく | 参加するかどうか**はともかく**、申し込みだけはしておこう。 |

## Nyanssi ja rajoitukset
- Sivuutettu asia (はともかく edellä) ei ole merkityksetön, mutta puhuja päättää keskittyä johonkin muuhun tässä yhteydessä.
- Yleinen kaava: N1はともかく、N2は〜 — vertaa implisiittisesti kahta ominaisuutta ja korostaa jälkimmäistä.
