> [!abstract] Ydin
> と yhdistää kaksi (tai useamman) substantiivin **täydellisen** listan: "A ja B" — kaikki mainitut, ei muuta. Eri と kuin lauseita yhdistävä [[～と (aina kun, väistämätön seuraus)]] (automaattinen seuraus, N4).

## Merkitys
- **FI:** A ja B
- **EN:** A and B (connecting nouns)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N1 と N2 | 土曜日**と**日曜日 |
| N1 と N2 と N3 | (jatkuu samalla kaavalla useammalle) |

## Nyanssi ja rajoitukset
- と listaa **kaiken** — jos listassa on vain esimerkkejä eikä kaikkea, käytetään myöhemmin opittavaa 〜や〜（など） ([[Minna no Nihongo I#Luku 10]]).
- Yhdistää vain substantiiveja, ei lauseita — lauseiden yhdistämiseen on eri rakenteita.

## Sekaannusvaara
Vertailu: [[～と (aina kun, väistämätön seuraus)]] (N4, [[Minna no Nihongo I#Luku 23]]) käyttää samaa partikkelia と mutta yhdistää **lauseita** merkityksessä "aina kun X, niin Y" — täysin eri kielioppi samalla kirjaimella. Tässä (Luku 4) と on aina vain substantiivien listaaja.

## Kortit
#flashcards/grammar/n5

土曜日と日曜日 — mitä と täällä tekee?
?
Yhdistää kaksi substantiivia täydelliseksi listaksi: "lauantai JA sunnuntai" (ei mitään muuta).

Miten tämä と eroaa myöhemmin opittavasta ～と (aina kun, väistämätön seuraus)-kieliopista?
?
Tämä と yhdistää substantiiveja (N1とN2). Myöhempi ～と yhdistää lauseita ja tarkoittaa "aina kun X tapahtuu, Y seuraa automaattisesti."

#flashcards/grammar/n5/muodostus

N1とN2 + kaksi substantiivia :: N1 と N2. Esim. 土曜日と日曜日
N1とN2 + useampi substantiivi :: N1 と N2 と N3 — sama kaava jatkuu.

#flashcards/grammar/n5/nyanssi

Mitä N1とN2 listaa, ja mitä käytetään epätäydelliselle listalle?
?
と listaa kaiken (täydellinen lista); esimerkkilistaan käytetään 〜や〜（など）.

Mitä N1とN2 yhdistää ja mitä ei?
?
Vain substantiiveja, ei lauseita.

#flashcards/grammar/n5/sekaannus

Miten N1とN2 (ja) と eroaa lauseita yhdistävästä ～と (aina kun)?
?
N1とN2:n と listaa substantiiveja ('A ja B'); ～と (N4) yhdistää lauseita merkityksessä 'aina kun X, niin Y'.
