> [!abstract] Ydin
> んだって on erittäin puhekielinen kuulopuhe-ilmaus: "kuulin että...eikö niin?" — vahvistaa toiselta kuultua tietoa keskustelukumppanilta, usein kysyvänä.

## Merkitys
- **FI:** kuulemma, eikö niin? (puhekielinen kuulopuhe/varmistus)
- **EN:** I heard that..., right?

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + んだって？ | いずみさんの結婚式でスピーチをした**んだって**? |
| | 大学院の試験に合格した**んだって**? おめでとう。 |
| | 山田さん、会社を辞める**んだって**? |
| | 田中さんが結婚する**んだって**? ……そうらしいですね。 |

## Nyanssi ja rajoitukset
- Selvästi puhekielisempi kuin そうです/らしい — käytetään lähinnä tuttavallisessa keskustelussa, usein kysymyksenä joka aloittaa uuden aiheen ("kuulin juttua X:stä, onko totta?").
- ってpääte tulee 〜ということだ:n puhekielisestä supistumasta (と言っていた → って); んだ tuo mukaan selittävän/kontekstoivan sävyn.
- Ei sovi muodolliseen tai kirjalliseen rekisteriin.
