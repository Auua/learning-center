> [!abstract] Ydin
> N + に加えて = **"N:n lisäksi"** — muodollinen lisäys, usein samansuuntaisia asioita.

## Merkitys
- **FI:** lisäksi, -n ohella
- **EN:** in addition to, besides

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + に加えて | 雨**に加えて**、風も強くなった。 |
| N + に加え（kirjallinen） | 授業料**に加え**、教材費もかかる。 |
| V普通形 + の + に加えて | 給料が安い**のに加えて**、休みも少ない。 |

## Nyanssi ja rajoitukset
- Muodollinen; uutiset ja tiedotteet.
- Jälkiosassa usein も.
- Verbi nominalisoidaan: 〜のに加えて.
