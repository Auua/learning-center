> [!abstract] Ydin
> 以上（は） toteaa, että koska mainittu tosiasia/tila **on jo voimassa**, siitä seuraa väistämättä tietty velvoite tai toimintatapa — hyvin lähellä からには:ta.

## Merkitys
- **FI:** koska kerran, sen jälkeen kun on niin (tosiasian sanelema seuraus)
- **EN:** given that, now that (this being the case)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + 以上（は） | たった一人で、人跡絶えた山奥にでも住まぬ**以上**、型にはまらないで暮らすわけにはゆきません。 |
| | 相手が「うん」と言わぬ**以上**、あきらめるしかありません。 |
| | 家賃が払えない**以上**、出ていくしかない。 |
| | 結論が出た**以上**、実施に向けて計画を進めます。 |
| | 住民の意見を受け入れた**以上**、市は一日も早く開発を進めてほしい。 |

## Nyanssi ja rajoitukset
- Jälkilause on lähes aina velvoite/päättäväisyys (〜わけにはいかない, 〜しかない, 〜なければならない) — hyvin samankaltainen kuin [[Vからには (koska kerran, paatoksen jalkeen)]].
- Ero on hienovarainen: 以上 korostaa hieman enemmän **jo voimassa olevaa objektiivista tosiasiaa/tilaa**; からには korostaa hieman enemmän **omaa päätöstä/sitoumusta**.

## Sekaannusvaara
- [[Vからには (koska kerran, paatoksen jalkeen)]]: käytännössä lähes vaihtokelpoinen; からには sopii hieman paremmin omaan päätökseen perustuvaan sitoumukseen (大学院に入ったからには), 以上 sopii hieman paremmin ulkoiseen, jo vakiintuneeseen tosiasiaan (結論が出た以上).
