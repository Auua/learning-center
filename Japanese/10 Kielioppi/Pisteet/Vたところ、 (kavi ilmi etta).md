> [!abstract] Ydin
> Vたところ、(pilkku, ei に/で) yhdistää kaksi lausetta: ensimmäinen teko johtaa jälkimmäiseen **havaintoon/löytöön** — "kun tein X, kävi ilmi että Y". Jälkilause on usein yllättävä tai informatiivinen.

## Merkitys
- **FI:** kun tein X, kävi ilmi että/huomasin että
- **EN:** when I did X, it turned out that / I found that

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V(た形) + ところ、+ havainto | 不審に思って振込口座名を調べた**ところ**、既に口座は閉じられていた。 |
| | 教授に大学新聞への原稿をお願いした**ところ**、すぐに引き受けてくださった。 |
| | 財布を落としたので、警察に行った**ところ**、ちょうど拾った人が届けに来ていた。 |
| | 身分証明書が必要かどうか確かめた**ところ**、不要だということだった。 |

## Nyanssi ja rajoitukset
- Jälkilause on aina **puhujan tahdosta riippumaton havainto/tulos**, ei suunniteltu seuraus — usein käytetään kertomaan yllättävästä löydöstä tutkimuksen/kyselyn jälkeen.
- Eroaa selvästi [[Vたところに・で (juuri siina kohdassa)]]:sta: tämä (pilkulla, ilman に/で) on looginen seuraussuhde ("tein X ja sitten selvisi Y"), kun taas ところに／で on ajallinen/paikallinen yhteensattuma ("juuri silloin kun X tapahtui, Y ilmestyi").

## Sekaannusvaara
- [[Vたところに・で (juuri siina kohdassa)]]: に/で-versio kuvaa ajallista/paikallista yhteensattumaa (シャワーを浴びているところに電話が鳴った); pilkullinen ところ、 kuvaa loogista seurausta/havaintoa toiminnasta (調べたところ、〜ことが分かった).
