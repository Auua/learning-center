> [!abstract] Ydin
> N + 向き = **"sopii N:lle"** — ominaisuuksiltaan sopiva, oli se tarkoitettu tai ei.

## Merkitys
- **FI:** sopiva jollekin, -lle sopiva
- **EN:** suitable for, good for

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + 向きの + N | 初心者**向きの**山 |
| N + 向きだ | この仕事は私には**向きではない**。 |
| 不向き（sopimaton） | 彼は営業には**不向き**だ。 |

## Nyanssi ja rajoitukset
- Arvio ominaisuuksista: 子ども向きの料理 = ruoka, joka sopii lapsille (mieto, helppo).
- 向いている on verbimuoto: 彼は教師に向いている (hän sopii opettajaksi).
- Kielto: 向きではない / 不向きだ.

## Sekaannusvaara
- 向け = tekijän tarkoitus (kohderyhmä); 向き = ominaisuuksiin perustuva soveltuvuus.
