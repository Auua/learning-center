> [!abstract] Ydin
> ったら liitetään henkilön nimeen/sanaan puhuteltaessa lievän **turhautumisen, hämmästyksen tai hellän moitteen** sävyllä — "voi tuota X:ää" tyyppinen huudahdus.

## Merkitys
- **FI:** voi tuota (X:ää), kunhan (X) on sellainen (lievä turhautunut/hellä moite)
- **EN:** honestly, that (person) — mildly exasperated address

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N（nimi/sana） + ったら | 優太**ったら**。（lapsen sanottua jotain hassua） |
| | お母さん**ったら**、どうして子どもの名前を間違えて呼ぶのよ。 |
| | うちで飼ってるチロ**ったら**、私のことを母親だと思ってるんですよ。 |
| | 林さん**ったら**、海外出張なのにパスポートを忘れて、飛行機に乗れなかったのよ。 |

## Nyanssi ja rajoitukset
- Sävy on yleensä **lempeä/huvittunut** moite, ei vihainen — käytetään läheisistä ihmisistä (perheenjäsenet, lemmikit, läheiset ystävät) kerrottaessa hassuista/ärsyttävistä tapahtumista.
- Erittäin puhekielinen, tyypillinen naisten/perhepiirin puheessa mutta ei rajoitu siihen.
- Voi seurata joko yksinään (nimi + ったら。) tai jatkua täydellä lauseella joka selittää mistä on kyse.

林さん＿＿＿＿、海外出張なのにパスポートを忘れて、飛行機に乗れなかったのよ。(lempeä turhautunut puhuttelu)

ったら — puhekielinen puhuttelupartikkeli, lievä turhautunut/huvittunut moite läheisestä henkilöstä.

#flashcards/grammar/n2/muodostus

N＋ったら + nimi tai sana :: N（nimi/sana）+ ったら. Esim. お母さんったら、どうして子どもの名前を間違えて呼ぶのよ。

#flashcards/grammar/n2/nyanssi

Mikä on N＋ったら:n sävy?
?
Yleensä lempeä tai huvittunut moite (turhautuminen, hämmästys), ei vihainen; käytetään läheisistä ihmisistä, lemmikeistä.

Miten N＋ったら voidaan jatkaa?
?
Voi seistä yksin (優太ったら。) tai jatkua lauseella, joka selittää mistä on kyse.
