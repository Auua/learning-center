> [!abstract] Ydin
> と言える esittää väitteen **perusteltuna johtopäätöksenä** — "voidaan sanoa että" — pehmeämpi ja perustellumpi kuin suora toteamus, tyypillinen argumentoivassa tekstissä.

## Merkitys
- **FI:** voidaan sanoa että
- **EN:** it can be said that, one could say

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + と言える | 15年ほどの間に食事のとり方も大きく変化してきた**と言えます**。 |
| | 日本の経済力を考えると、国際社会における日本の責任は大きい**と言える**。 |
| | 人口増加によって、地球温暖化はますます進む**と言えるのではないでしょうか**。 |
| | お金があれば幸せだ**と言えるのでしょうか**。（retorinen kysymys） |

## Nyanssi ja rajoitukset
- Perustuu tyypillisesti edellä esitettyyn dataan/perusteluun — kuuluu argumentoivan/analyyttisen tekstin vakiokalustoon.
- と言えるのではないでしょうか yhdistää tämän [[普通形のではないだろうか (varovainen oletus)]]:n kanssa entistä varovaisemmaksi väitteeksi.
