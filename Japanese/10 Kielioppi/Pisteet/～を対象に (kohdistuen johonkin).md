> [!abstract] Ydin
> を対象に merkitsee ryhmän/joukon, jolle jokin (ohjelma, tutkimus, tuote) on **suunnattu/kohdistettu** — muodollinen kohderyhmän ilmaus.

## Merkitys
- **FI:** kohdistuen johonkin, jollekin kohderyhmälle suunnattu
- **EN:** targeting, aimed at (a group)

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + を対象に + V | ロボコンは初めのころはNHKの番組で、大学や高専の学生**を対象に**行われていた。 |
| | 幼児**を対象に**開発されたゲームが、大人の間で流行している。 |
| | テレビの午後の番組はおもに主婦**を対象に**組まれている。 |
| | 大学生**を対象に**、漢字の能力を調査した。 |

## Nyanssi ja rajoitukset
- Muodollinen ilmaus, tyypillinen tutkimuksissa, ohjelmasuunnittelussa ja tuotekehityksessä kertomaan kenelle jokin on suunnattu.
- Ei sekoiteta を対象と**する**:iin (toisinaan esiintyvä variantti, "ottaa kohteeksi").
