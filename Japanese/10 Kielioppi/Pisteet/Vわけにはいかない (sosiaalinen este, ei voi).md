> [!abstract] Ydin
> わけにはいかない toteaa, että jokin teko ei ole mahdollinen **sosiaalisten/moraalisten normien** vuoksi, vaikka se olisikin fyysisesti mahdollinen — "en voi (koska se ei sovi/olisi väärin)".

## Merkitys
- **FI:** ei voi (sosiaalisista/moraalisista syistä), ei sovi tehdä
- **EN:** cannot (for social/moral reasons), can't afford to

## Muodostus
| Kaava | Esimerkki |
|---|---|
| V辞書形 + わけにはいかない | 面倒くさいきずなを切りさかぬかぎり、型にはまらないで暮らす**わけにはゆきません**。 |
| | 子どもの学費のために貯金してきたこのお金を使う**わけにはいかない**。 |
| | 遅刻も3回も4回も重なると許す**わけにはいかない**。 |
| V(ない形) + わけにはいかない | 失業中だからといって、親に頼る**わけにはいかない**。 |
| | 宿題が終わらないうちは、寝る**わけにはいかない**。 |

## Nyanssi ja rajoitukset
- Ero [[Vしかない (ei ole muuta vaihtoehtoa)]]:sta: わけにはいかない korostaa, että teko on **kiellettyä normien/velvollisuuksien vuoksi** (vaikka olisi mahdollista); しかない korostaa ettei muita **käytännön** vaihtoehtoja ole.
- Kielteinen muoto (Vないわけにはいかない) tarkoittaa päinvastoin: "on pakko tehdä" (ei voi olla tekemättä).

## Sekaannusvaara
- [[Vしかない (ei ole muuta vaihtoehtoa)]]: käytännön/tilanteen sanelema ainoa vaihtoehto; わけにはいかない on sosiaalisen/moraalisen normin sanelema kielto tai velvoite, ei käytännön pakko.
