> [!abstract] Ydin
> N + が + 必要だ = **"N on tarpeen, tarvitaan N"**. 必要 on な-adjektiivi.

## Merkitys
- **FI:** tarvitaan, on tarpeellinen
- **EN:** N is necessary, need N

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + が必要です | ビザ**が必要です**。 |
| N + には + N + が必要だ | 留学**には**お金**が必要だ**。 |
| 必要な + N | 旅行に**必要な**物 |

## Nyanssi ja rajoitukset
- Tarvitsija/tarkoitus merkitään に:llä tai には:llä: 私にはあなたが必要です.
- Arkikielessä usein 要る（いる）: お金が要る.
- Kielto: 必要ない／必要じゃない = ei tarvita.
