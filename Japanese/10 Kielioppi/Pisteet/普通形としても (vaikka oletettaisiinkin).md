> [!abstract] Ydin
> としても ottaa jonkin **hypoteettisen/oletetun tilanteen** myönnytyksenä — "vaikka oletettaisiinkin että X on totta, silti Y" — usein たとえ:n kanssa vahvistettuna.

## Merkitys
- **FI:** vaikka oletettaisiinkin että, vaikka olisikin niin että
- **EN:** even if we assume that, even supposing that

## Muodostus
| Kaava | Esimerkki |
|---|---|
| 普通形 + としても | 保育所があった**としても**、費用が高い。 |
| たとえ + 普通形 + としても | **たとえ**天と地がひっくり返った**としても**、私は驚かない。 |
| | **たとえ**彼女が本当にそう言った**としても**、彼女に対する私の愛は変わらない。 |
| | **たとえ**世界が一つの国になった**としても**、日本語はなくなってほしくない。 |

## Nyanssi ja rajoitukset
- Erityisen luonteva hypoteettisille/epätodennäköisille tai äärimmäisille oletuksille (天と地がひっくり返る) — korostaa ettei edes äärimmäinen oletus muuttaisi lopputulosta.
- たとえ yhdistyy tähän luontevasti samaan tapaan kuin [[たとえ～ても (vaikka kuinka)]]:n kanssa.

## Sekaannusvaara
- [[たとえ～ても (vaikka kuinka)]]: ても liittyy suoraan verbiin/adjektiiviin; としても liittyy erityisesti **oletukseen/väitteeseen** (usein ~だ + としても), sopien tilanteisiin joissa myönnetään hypoteesi ennen sen kumoamista.
