> [!abstract] Ydin
> N + 並み = **"N:n tasoinen, N:ää vastaava"** — 平年並み, プロ並み, 人並み.

## Merkitys
- **FI:** tasoinen, -n veroinen, tavanomainen
- **EN:** on par with, average, like

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + 並みの + N | プロ**並みの**腕前 |
| N + 並みに | 夏**並みに**暑い。 |
| 人並み（tavallinen） | **人並み**の生活がしたい。 |

## Nyanssi ja rajoitukset
- 平年並み = tavanomaisella tasolla (sää); 人並み = tavallisen ihmisen tasoa.
- Myös: 町並み, 家並み (rivistö) — eri merkitys.
