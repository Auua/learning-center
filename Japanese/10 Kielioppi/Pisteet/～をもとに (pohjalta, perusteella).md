> [!abstract] Ydin
> N + をもとに = **"N:n pohjalta, N:ää aineistona käyttäen"** — luova työ syntyy N:stä.

## Merkitys
- **FI:** pohjalta, aineistona, perusteella
- **EN:** based on, using as material

## Muodostus
| Kaava | Esimerkki |
|---|---|
| N + をもとに + V | 実話**をもとに**映画を作った。 |
| N + をもとにした + N | アンケート**をもとにした**報告書 |

## Nyanssi ja rajoitukset
- N on raaka-aine tai inspiraatio, josta jotain uutta luodaan: 小説, 映画, 計画.
- に基づいて on tiukempi: sääntö tai tieto perusteena.

## Sekaannusvaara
- 法律に基づいて (lain perusteella — tiukka) vs. 実話をもとに (tositarinan pohjalta — luova muokkaus).
