> [!abstract] Ydin
> "Jos kerran on niin, että A — niin B." Reagoi siihen mitä toinen juuri sanoi tai mikä on tilanteesta selvää. Ainoa ehtolause, jossa B voi tapahtua **ennen** A:ta.

## Merkitys
- **FI:** jos kerran / mitä tulee A:han
- **EN:** if it is the case that / speaking of

## Muodostus
| Mihin liittyy | Kaava | Esimerkki |
|---|---|---|
| Substantiivi | N + なら | 温泉なら、伊豆がいい。 |
| な-adjektiivi | + なら | 便利なら |
| い-adjektiivi | い + なら | 高いなら |
| Verbi | [[Sanakirjamuoto]] / [[た-muoto]] + なら | 行くなら / 行ったなら |

## Nyanssi ja rajoitukset
- Vaatii **kontekstin**: toisen puheenvuoron, näkyvän tilanteen tai jaetun oletuksen. Ei sovi tyhjästä aloitettuun lauseeseen.
- **Aikajärjestys voi kääntyä:** 日本に行くなら、ガイドブックを買ったほうがいい。(kirja ostetaan ennen matkaa). Vertaa: 日本に行っ**たら**、ガイドブックを買う。(kirja ostetaan Japanissa).
- Toimii aiheen nostona: 日本語なら、少し話せます。

#flashcards/grammar/n4

なら — mikä erottaa sen たら:sta?
?
なら reagoi kontekstiin tai toisen puheenvuoroon, ja jälkilauseen toiminta voi tapahtua ENNEN etulauseen toimintaa. 行くなら買う = ostetaan ennen lähtöä; 行ったら買う = ostetaan perillä.

#flashcards/grammar/n4/muodostus

～なら + substantiivi :: N + なら. Esim. 温泉なら、伊豆がいい。
～なら + な-adjektiivi :: な-adj + なら. Esim. 便利なら
～なら + い-adjektiivi :: い-adj + なら. Esim. 高いなら
～なら + verbi :: Sanakirjamuoto／た-muoto + なら. Esim. 行くなら／行ったなら

#flashcards/grammar/n4/nyanssi

Mitä ～なら vaatii ympärilleen, jotta lause on luonteva?
?
Kontekstin: toisen puheenvuoron, näkyvän tilanteen tai jaetun oletuksen. Ei sovi tyhjästä aloitettuun lauseeseen.

Miten aikajärjestys toimii ～なら-lauseessa?
?
Jälkilauseen toiminta voi tapahtua ennen etulausetta: 日本に行くなら、ガイドブックを買ったほうがいい (kirja ostetaan ennen matkaa).

Miten ～なら toimii aiheen nostona?
?
Nostaa aiheen esiin: 日本語なら、少し話せます (mitä japaniin tulee, puhun vähän).

#flashcards/grammar/n4/sekaannus

Miten ～なら eroaa ～たら:sta, kun lause on 日本に行く…、ガイドブックを買う?
?
行くなら買う = kirja ostetaan ennen matkaa (reagoi kontekstiin); 行ったら買う = kirja ostetaan Japanissa.
