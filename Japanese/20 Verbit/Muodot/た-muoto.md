> [!abstract] Mihin tätä tarvitaan
> Menneisyys ei-kohteliaasti, ja pohja rakenteille ～たら、～たことがある、～たり～たり、～たほうがいい、～たばかり.

## Merkitys
- **FI:** menneisyys ei-kohteliaasti; kokemus; pohja ehtomuodolle
- **EN:** plain past (ta-form)

## Muodostussäännöt
Täsmälleen sama sääntö kuin [[て-muoto]], mutta て → た ja で → だ.

| Verbityyppi | て-muoto | た-muoto |
|---|---|---|
| 買う | 買って | 買った |
| 飲む | 飲んで | 飲んだ |
| 書く | 書いて | 書いた |
| 泳ぐ | 泳いで | 泳いだ |
| 話す | 話して | 話した |
| 食べる | 食べて | 食べた |
| する / 来る | して / 来て | した / 来た |

## Poikkeukset
- **行く → 行った**

#flashcards/form/n5/saanto

た形 :: sama sääntö kuin て形, mutta て → た ja で → だ
た形 + 五段 う・つ・る :: → った (買う → 買った)
た形 + 五段 む・ぶ・ぬ :: → んだ (飲む → 飲んだ)
た形 + 五段 く :: → いた (書く → 書いた)
た形 + 五段 ぐ :: → いだ (泳ぐ → 泳いだ)
た形 + 五段 す :: → した (話す → 話した)
た形 + 一段 :: る → た (食べる → 食べた)
た形 + 不規則 :: する → した、来る → 来た
