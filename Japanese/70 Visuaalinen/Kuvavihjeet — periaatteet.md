# Kuvavihjeet

Kuvavihje toimii silloin kun se on **outo, konkreettinen ja liikkuva**. Abstrakti kuva ei tartu.

## Kolme tyyppiä

### 1. Kanjin muistisääntö (osista tarina)
Käytä aina samoja merkityksiä samoille osille — muuten tarinat sekoittuvat keskenään. Osien merkitykset ovat kansiossa `40 Kanji/Osat`, esim. [[門]], [[欠]], [[彳]].
Esimerkki: [[開]] = [[門]] portti + kaksi kättä nostamassa salpaa.

### 2. Kieliopin skeemakuva
Piirrä **rakenne**, ei merkitystä. Ehtolauseet on aikajana + nuoli:
- [[～たら (jos, kun)]] · [[～と (aina kun, väistämätön seuraus)]] · [[～ば (jos, ehto)]] → 🅰️ ──▶ 🅱️
- [[～なら (jos kerran)]] → 🅱️ ◀── 🅰️ (jälkilause voi tapahtua ensin)

### 3. Sanan tilannekuva
Sana yhdistettynä paikkaan jossa sen oikeasti kohtaa. [[温泉]] → ryokanin sisäänkirjautuminen, ei sanakirjarivi.

## Työnkulku Excalidrawilla
1. `Ctrl/Cmd+P` → *Excalidraw: Create new drawing*
2. Tallenna kansioon `70 Visuaalinen`
3. Upota muistiinpanoon: `![[Piirros — ehtolauseet.excalidraw]]`
4. Linkitä takaisin lähdemuistiinpanoon, niin piirros näkyy sen backlinkeissä

## Kuvatiedostot
Liitteet menevät automaattisesti kansioon `70 Visuaalinen/liitteet` (asetettu vaultin asetuksissa).

## Muistisääntö muistisäännöille
Jos joudut selittämään kuvan itsellesi, se on liian abstrakti. Vaihda se johonkin jonka voisi valokuvata.
